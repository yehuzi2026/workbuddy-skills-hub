# 标书方案排版 — Word 文档标题排版与目录生成

## 职责边界（v2.0.0 新增，四技能流程审计 P0-3 修复）

> ⚠️ **本技能在四技能组合流程中的定位：仅负责多级编号 + TOC 补充 + 格式校验。不负责字体/字号/行距/分页符等格式参数的设置或修改。**

|------|---------|------|
| 内容编写 | 编写技能 Phase 3 | 方案正文+表格内容 |

| 分页符 | 编写技能 Phase 5.5 | H1/H2/H3 前加分页符 |

| **字体（宋体）** | **编写技能 Phase 5.5** | **三步骤干净设置，含主题引用删除** |

**核心禁令（v2.0.0）：**
- ❌ **禁止修改已有标题的字体（不将宋体改为黑体）**
- ❌ **禁止修改已有标题的字号（不覆盖 14pt/12pt）**
- ❌ **禁止修改行距（不修改 1.5 倍行距）**
- ❌ **禁止修改/新增/删除分页符**
- ✅ **仅添加/修复 outlineLvl（大纲级别）和 numPr（编号绑定）**
- ✅ **仅当 numbering.xml 不存在时创建**
- ✅ **仅当 TOC 域不存在时插入**

## 功能概述

将编写技能生成的 DOCX 文档，自动补全多级编号绑定（创建 numbering.xml）、修复大纲级别（outlineLvl），确保 TOC 目录可更新、导航窗格可用。

## 核心问题与解决思路

### 问题 1：styles.xml 缺少标题样式定义

很多 docx 文件（尤其从网页或其他格式转换而来）的 `styles.xml` 中**只包含 Normal 等基础样式**，没有 `Heading1/2/3` 定义。即使段落的 `pStyle` 设为 `Heading1`，WPS/Word 也会因找不到样式定义而回退为正文，导致目录生成失败。

**解决**：在 `styles.xml` 中补全 `Title`、`Heading1`、`Heading2`、`Heading3`、`TOCHeading` 样式定义，每个都要设置：
- `outlineLvl`（0/1/2）— 目录识别的核心依据
- `numPr`（numId + ilvl）— 绑定多级编号列表
- 字体格式（宋体、加粗、字号）

### 问题 2：标题文字中硬编码了编号

原始文档标题如 "第一章 项目需求..."、"1.1 项目背景..."，编号是文字的一部分。当应用多级编号时会出现双重编号（"1. 第一章..."）。

**解决**：使用正则表达式识别并删除标题文字中的编号前缀，让编号完全由 Word 的多级列表自动生成。

### 问题 3：缺少 numbering.xml

标题样式的 `numPr` 引用了编号列表 ID，但 docx 中可能没有 `numbering.xml` 文件。

**解决**：创建 `word/numbering.xml`，定义多级列表（Level 0: 第%1章, Level 1: %1.%2, Level 2: %1.%2.%3），并在 `[Content_Types].xml` 和 `document.xml.rels` 中注册引用。

### 问题 4：手动点击"多级编号"覆盖样式设置

WPS 的"多级编号"按钮触发的是**手动编号**，会覆盖样式自带的编号，导致编号叠加或错乱。

**解决**：向用户说明：
- **不要**全选后点击"多级编号"
- 文档打开后，样式绑定的编号应**自动生效**
- 如需修改编号款式，应修改样式定义中的 `numFmt` 和 `lvlText`
- 若已误操作，全选 → "多级编号"→"无"可清除手动编号，恢复样式编号

## 执行流程

### 步骤 0：上游检测 — 识别文档来源（v2.39.1 升级双版本+表格色系识别，强制，最先执行）

> ⚠️ **v2.39.1：上游 md2docx.py 现输出双版本——「打印版」（标题含纯文本序号）和「粘贴版」（标题无序号）。排版技能需识别版本类型并适配处理。同时新增表格色系完整性检测。**

**检测流程（v2.39.1 新增双版本识别 + 表格色系检测）：**

```
打开 DOCX ZIP 包，检测 word/document.xml：

  0. 【v2.39.1 新增】文档版本+色系识别：
     搜索 word/document.xml 标题文字 + 表格色系：
     ① Heading 1 文字是否以中文序号开头？ → 打印版 / 粘贴版
     ② 表头 <w:shd w:fill> 是 #4472C4（彩色）还是 #333333（黑白）？
     └── 判定结果写入日志："📋 版本：[打印/粘贴] | 色系：[彩色/黑白]"
         打印版 → 标题已有序号，排版不修改标题文字
         粘贴版 → 标题无序号，排版不添加序号

  1. 【v2.39.1 新增】表格色系完整性检测：
     搜索所有 <w:shd w:fill>：
     ① 彩色模式：表头==#4472C4？斑马纹 #F0F3FA/#FFFFFF？
     ② 黑白模式：表头==#333333？数据行==#FFFFFF？
     ③ firstLine==0？（首行缩进已清零）
     └── 不满足 → 标记「⚠️ 表格色系不完整」

  2. 搜索 <w:instrText> 中是否包含 "TOC" 关键字
     ├── 有 → TOC 域已存在 → 跳过步骤 7（不再插入 TOC）
     └── 无 → 执行步骤 7（插入 TOC）

  3. 检查 word/styles.xml 中是否存在 Heading1/2/3 样式定义
   └── 若有且含 outlineLvl →
         跳过步骤 5（样式修改）——上游已生成完整样式
         仅记录日志："✅ Heading 样式已完整（含 outlineLvl），跳过样式修改"

  4. 检查 word/numbering.xml 是否存在
     ├── 有 → 跳过步骤 4（不覆盖已有编号列表）
     └── 无 → 执行步骤 4（创建编号列表）

  5. 检测文档中是否包含 <w:tbl> 表格元素
     ├── 有 → 进入「表格保护模式」（步骤 2 跳过表格单元格内的段落）
     └── 无 → 正常流程
```

**上述检测完成后，将检测结果（含来源判定）写入步骤 1 的分析日志。**

### 步骤 1：读取并分析 docx 结构

使用 `zipfile` 读取 docx（本质是 ZIP 包），检查以下文件是否存在：
- `word/document.xml` — 段落内容（**特别关注 `<w:tbl>` 表格元素的位置**）
- `word/styles.xml` — 样式定义
- `word/numbering.xml` — 编号列表（通常缺失）
- `word/_rels/document.xml.rels` — 关系引用
- `[Content_Types].xml` — 内容类型声明

**分析日志输出（v2.29.0 升级）：**

```
📋 DOCX 结构分析
  ├── 来源判定：[货物类自动生成 / 服务类自动生成 / 未知来源]
  ├── TOC 域：已检测到 / 未检测到
  ├── Heading 样式：已定义 / 未定义
  ├── numbering.xml：已存在 / 需创建
  └── 表格元素：X 个（位于段落索引 Y1, Y2, ...）
```

### 步骤 2：识别标题层级（v2.28.1 新增表格保护）

遍历 `document.xml` 中所有段落的文本内容，根据正则规则判断层级。**关键规则：跳过所有 `<w:tbl>` 表格单元格内的 `<w:p>` 段落。**

**表格保护规则：**
1. 遍历 `document.xml` 前，先定位所有 `<w:tbl>` 元素及其子 `<w:tc>` 中所有 `<w:p>` 的位置
2. 这些 `<w:p>` 在标题识别阶段**直接跳过**，不参与标题层级判断
3. 这样可以避免表格内的加粗术语被误识别为标题，导致表格单元格被错误地赋予 `pStyle="HeadingN"` 而变形

**识别规则：**

| 规则 | 示例 | 对应样式 |
|------|------|---------|
| `^第[一二三四五六七八九十百千万]+章` | "第一章 项目需求..." | Heading 1 |
| `^\d+\.\d+\s` | "1.1 项目背景..." | Heading 2 |
| `^\d+\.\d+\.\d+\s` | "1.1.1 保险行业..." | Heading 3 |
| 精确匹配 "技术方案" | "技术方案" | Title |

### 步骤 3：删除硬编码编号

对识别到的标题段落，删除文本中的编号部分：
- Heading 1: `re.sub(r'^第[一二三四五六七八九十百千万]+章\s*', '', text)`
- Heading 2: `re.sub(r'^\d+\.\d+\s+', '', text)`
- Heading 3: `re.sub(r'^\d+\.\d+\.\d+\s+', '', text)`

### 步骤 4：创建 numbering.xml

```xml
<w:numbering xmlns:w="http://schemas.openxmlformats.org/wordprocessingml/2006/main">
  <w:abstractNum w:abstractNumId="0">
    <w:multiLevelType w:val="multilevel"/>
    <w:lvl w:ilvl="0">
      <w:start w:val="1"/>
      <w:numFmt w:val="chineseCounting"/>
      <w:lvlText w:val="第%1章"/>
      <w:lvlJc w:val="left"/>
      <w:pPr><w:ind w:left="0" w:hanging="0"/></w:pPr>
      <w:rPr><!-- 字体格式 --></w:rPr>
    </w:lvl>
    <w:lvl w:ilvl="1">
      <w:start w:val="1"/>
      <w:numFmt w:val="decimal"/>
      <w:lvlText w:val="%1.%2"/>
      <w:lvlJc w:val="left"/>
      <w:pPr><w:ind w:left="420" w:hanging="420"/></w:pPr>
      <w:rPr><!-- 字体格式 --></w:rPr>
    </w:lvl>
    <w:lvl w:ilvl="2">
      <w:start w:val="1"/>
      <w:numFmt w:val="decimal"/>
      <w:lvlText w:val="%1.%2.%3"/>
      <w:lvlJc w:val="left"/>
      <w:pPr><w:ind w:left="840" w:hanging="840"/></w:pPr>
      <w:rPr><!-- 字体格式 --></w:rPr>
    </w:lvl>
  </w:abstractNum>
  <w:num w:numId="1">
    <w:abstractNumId w:val="0"/>
  </w:num>
</w:numbering>
```

### 步骤 5：更新 styles.xml（v2.0.0 职责边界修正）

> ⚠️ **v2.0.0 关键修正**：本步骤仅在 styles.xml 中**补齐或修复 `outlineLvl`（大纲级别）和 `numPr`（编号绑定）**。**禁止修改 `w:rFonts`（字体）、`w:sz`（字号）、`w:spacing`（行距/段间距）、分页属性**。这些格式参数由编写技能的 Phase 5.5 三步骤干净设置负责，排版技能不得覆盖。

**处理逻辑（v2.0.0）：**

```
对每个 HeadingN 样式定义进行增量修复：

1. 检查 <w:outlineLvl> 是否存在且值为正确的 N-1
   ├── 是 → 跳过
   └── 否/缺失 → 添加或修正 <w:outlineLvl w:val="N-1"/>

2. 检查 <w:numPr> 是否存在且绑定正确
   ├── 是 → 跳过
   └── 否/缺失 → 添加 <w:numPr> 绑定编号列表

3. 检查 <w:rFonts>（字体）、<w:sz>（字号）、<w:spacing>（间距）
   ├── 已有定义 → 跳过，不覆盖
   └── 完全缺失（裸样式）→ 才补全为宋体默认值
```

**仅当样式定义完全缺失（styles.xml 中无 HeadingN 定义）时，才创建完整的新样式定义：**

```xml
<w:style w:type="paragraph" w:styleId="Heading1">
  <w:name w:val="heading 1"/>
  <w:basedOn w:val="Normal"/>
  <w:qFormat/>
  <w:pPr>
    <w:keepNext/>
    <w:keepLines/>
    <w:outlineLvl w:val="0"/>          <!-- 大纲级别，TOC 识别用 -->
    <w:numPr>                           <!-- 绑定多级编号 -->
      <w:numId w:val="1"/>
      <w:ilvl w:val="0"/>
    </w:numPr>
  </w:pPr>
  <w:rPr>
    <w:rFonts w:ascii="Times New Roman" w:hAnsi="Times New Roman" w:eastAsia="宋体"/>
    <w:b/>
    <w:bCs/>
    <w:sz w:val="28"/>
    <w:szCs w:val="28"/>
  </w:rPr>
</w:style>
```

Heading2/3 同理，`outlineLvl` 分别为 1/2，`ilvl` 分别为 1/2。

### 步骤 6：更新 document.xml

对每个标题段落（**跳过步骤 2 已标记的表格单元格内段落**）：
1. 删除硬编码编号（修改 `<w:t>` 文本）
2. 添加 `<w:pStyle w:val="HeadingN"/>`
3. 删除段落级别多余的 `<w:numPr>`（避免与样式冲突）

**TOC 插入（条件执行，v2.28.1 新增）：**

```
检查步骤 0 的 TOC 检测结果：
  ├── TOC 域已存在（如 md2docx.py 生成）→ 跳过 TOC 插入，只记录日志
  └── TOC 域不存在 → 在文档开头插入以下 TOC 域
```

**仅当 TOC 域不存在时**插入：
```xml
<w:p>
  <w:pPr><w:pStyle w:val="TOCHeading"/></w:pPr>
  <w:r><w:t>目录</w:t></w:r>
</w:p>
<w:p>
  <w:r><w:fldChar w:val="begin"/></w:r>
  <w:r><w:instrText xml:space="preserve"> TOC \o "1-3" \h \z \u </w:instrText></w:r>
  <w:r><w:fldChar w:val="separate"/></w:r>
  <w:r><w:t>（右键此处，选择"更新域"以生成目录）</w:t></w:r>
  <w:r><w:fldChar w:val="end"/></w:r>
</w:p>
```

### 步骤 7：更新关系引用

在 `word/_rels/document.xml.rels` 中添加：
```xml
<Relationship Id="rId999" 
  Type="http://schemas.openxmlformats.org/officeDocument/2006/relationships/numbering"
  Target="numbering.xml"/>
```

在 `[Content_Types].xml` 中添加：
```xml
<Override PartName="/word/numbering.xml"
  ContentType="application/vnd.openxmlformats-officedocument.wordprocessingml.numbering+xml"/>
```

### 步骤 8：保存并输出

将所有修改后的 XML 写回 ZIP，保存为新 docx 文件。

## 用户使用说明

1. 用 Word/WPS 打开处理后的文档
2. 翻到最上方的目录区域
3. **右键目录 → 更新域 → 更新整个目录**
4. 标题编号应自动显示（"第一章"/"1.1"/"1.1.1"）
5. **不要**全选后点击"多级编号"按钮，这会覆盖样式设置
6. 如需修改编号款式，在"样式"面板中右键对应标题样式 →"修改"→"格式"→"编号"

## 注意事项

- 修改前务必备份原始文件
- 某些复杂格式（如表格、图片）可能需要在处理前提取分析
- WPS 和 Word 对多级编号的渲染可能略有差异，建议在目标软件中测试
- 如果文档中已有真实的 Word 表格（非文本伪表格），处理逻辑需额外注意表格单元格内的标题

## 页面布局规范（v2.29.0 新增，来自编写技能 Phase 5.5）

> ⚠️ **v2.39.0 + v2.0.0 + v3.0.0 三重声明**：以下页面布局参数的权威定义源为「服务类技术方案主观分编写--小羊羊」→ `references/shared-constants.md`。本排版技能仅作校验基准使用，不主动修改任何已有页面布局参数。

**当上游 DOCX 已由编写技能生成时：**
- **仅校验**：读取文档中的页边距/行距/缩进/分页符 → 与以下基准对比 → 不一致则输出警告到日志 → **不修改文档**
- **用户可选择**：要求排版技能按本规范补齐未定义项（仅限文档完全缺失该属性时）

**当文档来源为未知（非编写技能生成）时：**
- 按本规范执行补齐。

### 一、行距全覆盖

- **标题行间距**：1.5 倍（H1/H2/H3 统一）
- **正文行间距**：1.5 倍
- 表格、TOC、空行、图片标题统一 1.5 倍行距。

### 二、页边距

上下 2.54cm，左右 3.18cm。

### 三、正文首行缩进

正文段落首行缩进 `Cm(0.74)`。

### 四～六、分页符规则

| 标题级别 | 分页规则 | 例外 |
|----------|----------|------|
| H1（章） | 每个 H1 前加分页符 | 第一个 H1 除外 |
| H2（节） | 每个 H2 前加分页符 | 紧接 H1 的第一个 H2 除外 |
| H3（小节） | 每个 H3 前加分页符 | 紧接 H2 的第一个 H3 除外 |

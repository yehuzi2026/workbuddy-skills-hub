# 战略深解 — 每天自动化的公众号

> SKILL.md §1 的延伸。这里放「为什么这么定」的细节，写稿/复盘自动化读 SKILL.md 即可，本文件供你想清楚时查阅。

## 一、为什么北极星从「阅读量」改成「粉丝数」

追求阅读量会导致：什么火写什么 → 来的是热点泛粉 → 看完就走、不看第二篇 → 取关率高 → 画像混乱 → 广告主不认、卖什么都没人买。

**10 万阅读带来 50 个泛粉，不如 3000 阅读带来 80 个精准粉。**

但注意：**新号（0 粉）的最大瓶颈是分发不是内容**。1 个粉丝的号发文默认曝光≈0，不解决分发（SEO + 站外导流 + 分享杠杆），内容质量再高也是自嗨。

## 二、三阶段路线图（数量 → 收益 → 志同道合）

### P1 冷启动（数量优先）：0 → 500 粉
- 北极星：净增粉丝数
- 核心动作：实名验证 → SEO 化选题 → （可选）站外导流 → 每篇埋三个涨粉钩子
- 内容：每日 2 篇，全部流量内容（追热点拉新），立场/筛人内容暂缓
- 不做：不追求阅读量数字、不做定位收窄、不接广告、不做付费产品
- 成功标志：500 粉，开通流量主

### P2 变现（数量→收益）：500 粉+
- 北极星：收益额 / 单粉产出
- 核心动作：开通并优化流量主；粉丝过线后接商单/软文；持续追热点保涨粉
- 成功标志：月收益稳定覆盖投入

### P3 志同道合（收益后）：收益稳定后启动
- 北极星：同频粉占比 / 取关率 < 2%
- 核心动作：收窄账号定位；建立固定立场栏目筛人；精准私域转化
- 成功标志：形成 1–2 个稳定高转化的固定栏目，粉丝画像清晰

## 三、变现路径与硬门槛

| 路径 | 硬门槛 | 收益量级 | 阶段 |
|---|---|---|---|
| 实名验证 | 号主身份证 | 变现总开关 | P0，必须最先做 |
| 流量主 | 500 粉 + 实名 | 千次阅读约 3–15 元，低 | P2 |
| 赞赏 | 实名 + 原创质量 | 不稳定 | P2 |
| 商单/软文 | 通常 5000 粉+ 或垂类精准 | 单条数百至数万 | P3 |
| 私域转化 | 无平台硬门槛，但需本人承接 | 天花板最高 | P2 起布局 |

**关键判断**：流量主不是目标，是里程碑；真正的收益天花板在私域转化，但那要等 P3。

## 四、内容配比的演进

- 早期想法：70% 流量 + 30% 立场（并行筛人）
- 用户决策修正：**先要粉丝数量，数量上来了就有收益，收益后再谈志同道合** → 当前阶段 2 篇全做流量内容，立场/筛人暂缓至 P3
- 理由：泛粉变现效率低于同频粉，但「数量→收益」在微信生态成立（过 500 粉开流量主），故先堆量到门槛，收益有了再回头提纯，比一开始就筛准更现实。

# 合规标准库

## 一、企业合规核心法规清单

### 1.1 公司治理合规

| 法规 | 核心合规要求 | 违规后果 |
|------|-----------|---------|
| 《公司法》 | 公司设立、治理结构、股权管理、合并分立、清算 | 行政处罚、民事赔偿、刑事责任 |
| 《证券法》 | 信息披露、内幕交易、操纵市场、收购 | 行政处罚（最高1000万）、民事赔偿、刑事责任 |
| 《上市公司治理准则》 | 独立董事、董事会专门委员会、内控 | 交易所监管措施、行政处罚 |
| 《企业内部控制基本规范》 | 内控体系建立与执行 | 上市公司须出具内控审计报告 |

### 1.2 合同交易合规

| 法规 | 核心合规要求 | 违规后果 |
|------|-----------|---------|
| 《民法典》合同编 | 合同效力、履行、违约责任 | 合同无效、违约赔偿 |
| 《电子商务法》 | 电子商务经营者义务、平台责任 | 行政处罚、民事赔偿 |
| 《反垄断法》 | 垄断协议、滥用支配地位、经营者集中 | 行政处罚（上一年度销售额1%-10%） |
| 《反不正当竞争法》 | 不正当竞争行为、商业秘密保护 | 行政处罚、民事赔偿 |

### 1.3 劳动用工合规

| 《劳动合同法》 | 合同订立、履行、解除、经济补偿 | 双倍工资、经济补偿、赔偿金 |
| 《社会保险法》 | 社保登记、缴费 | 行政处罚、滞纳金 |
| 《工伤保险条例》 | 工伤认定、待遇支付 | 工伤赔偿责任 |
| 《女职工劳动保护特别规定》 | 孕期/产期/哺乳期保护 | 行政处罚、劳动仲裁 |
| 《劳务派遣暂行规定》 | 派遣比例≤10%、同工同酬 | 行政处罚、劳动仲裁 |

### 1.4 知识产权合规

### 1.6 数据合规专项标准

#### 1.6.1 个人信息保护合规清单

**处理规则合规：**
- [ ] 是否遵循合法、正当、必要、诚信原则
- [ ] 是否具有明确、合理的目的
- [ ] 是否遵循最小必要原则（收集范围限于实现处理目的的最小范围）
- [ ] 是否实现处理目的的最短保存期限
- [ ] 是否保证个人信息质量（准确、完整）

**告知同意合规：**
- [ ] 是否在处理前以显著方式、清晰易懂的语言告知处理者信息、处理目的、方式、种类、保存期限、权利行使方式
- [ ] 是否取得个人同意（同意须自愿、明确）
- [ ] 敏感个人信息处理是否取得单独同意
- [ ] 跨境提供是否取得单独同意
- [ ] 处理目的、方式、种类变更是否重新取得同意

**个人权利保障合规：**
- [ ] 是否建立知情权、决定权保障机制
- [ ] 是否建立查阅、复制权保障机制
- [ ] 是否建立更正、补充权保障机制
- [ ] 是否建立删除权保障机制
- [ ] 是否建立可携带权保障机制
- [ ] 是否建立自动化决策拒绝权保障机制

**处理者义务合规：**
- [ ] 是否确定个人信息处理负责人
- [ ] 是否对从业人员进行培训
- [ ] 是否制定内部管理制度和操作规程
- [ ] 是否采取安全技术措施（加密、去标识化等）
- [ ] 是否制定应急预案
- [ ] 是否进行个人信息保护影响评估（PIA）

#### 1.6.2 数据安全合规清单

- [ ] 是否建立数据分类分级制度
- [ ] 是否梳理重要数据目录
- [ ] 是否采取数据安全保护措施
- [ ] 是否建立数据安全风险监测机制
- [ ] 是否建立数据安全事件应急机制
- [ ] 是否履行数据安全事件报告义务

#### 1.6.3 网络安全合规清单

- [ ] 是否履行网络运营者义务
- [ ] 是否完成网络安全等级保护定级备案
- [ ] 是否落实网络安全等级保护要求
- [ ] 是否建立网络安全事件应急机制
- [ ] 是否进行网络安全监测预警
- [ ] 关键信息基础设施运营者是否履行特殊保护义务

#### 1.6.4 数据跨境传输合规清单

- [ ] 是否识别数据出境情形
- [ ] 是否评估出境数据的重要程度
- [ ] 是否需要申报数据出境安全评估
- [ ] 是否通过安全评估/标准合同/认证
- [ ] 是否与境外接收方订立合同
- [ ] 是否履行个人信息保护影响评估

### 1.7 反腐败反贿赂合规

| 法规 | 核心合规要求 | 违规后果 |
|------|-----------|---------|
| 《刑法》 | 商业贿赂、贪污、职务侵占 | 刑事责任 |
| 《反不正当竞争法》 | 商业贿赂禁止 | 行政处罚（10-300万）、民事赔偿 |
| 《监察法》 | 公职人员职务违法调查 |政务处分、刑事责任 |
| 《公司法》 | 董监高忠实义务 | 民事赔偿、行政处罚 |

## 三、合规检查清单模板

### 3.1 通用合规检查清单

**公司治理：**
- [ ] 公司章程是否合规、是否与实际运作一致
- [ ] 股东会/董事会/监事会是否规范运作
- [ ] 关联交易是否履行回避表决与披露
- [ ] 重大决策是否有书面决议
- [ ] 信息披露是否真实、准确、完整、及时（上市公司）

**合同管理：**
- [ ] 是否有标准合同模板
- [ ] 合同是否经过法务审核
- [ ] 合同是否归档管理
- [ ] 合同履行是否有监控
- [ ] 合同变更是否有书面记录

**劳动用工：**
- [ ] 是否全员签订书面劳动合同
- [ ] 试用期约定是否合法
- [ ] 工资支付是否合规
- [ ] 社保是否足额缴纳
- [ ] 规章制度是否经过民主程序
- [ ] 加班安排是否合规
- [ ] 离职管理是否合规

**知识产权：**
- [ ] 核心知识产权是否登记/注册
- [ ] 职务发明权属是否明确
- [ ] 离职员工知识产权确认是否完成
- [ ] 产品上市前是否做FTO检索
- [ ] 商业秘密保护措施是否到位

**财税合规：**
- [ ] 会计核算是否合规
- [ ] 税务申报是否及时、准确
- [ ] 发票管理是否规范
- [ ] 关联交易定价是否公允
- [ ] 税收优惠资质是否持续满足

**数据合规：**
- [ ] 个人信息处理是否合规
- [ ] 数据安全保护措施是否到位
- [ ] 数据跨境传输是否合规
- [ ] 网络安全等级保护是否完成
- [ ] 是否建立数据安全事件应急机制

## 四、合规体系建设标准

### 4.1 ISO 37301合规管理体系

**七要素要求：**

1. **领导作用**：最高管理者须签署合规承诺、分配资源、推动合规文化
2. **合规方针**：制定明确的合规方针与目标，向全体员工传达
3. **组织结构**：设立合规职能部门，明确合规职责与权限
4. **策划**：识别合规义务、评估合规风险、制定合规目标
5. **支持**：提供资源、培训、沟通、文件化信息
6. **运行**：运行控制、外包过程控制、应急准备与响应
7. **绩效评价**：监视、测量、分析、评价、内部审核、管理评审

### 4.2 合规体系有效性评估

**评估维度：**
- 设计有效性：合规体系是否设计完善
- 执行有效性：合规体系是否有效执行
- 结果有效性：合规体系是否产生预期效果

**评估方法：**
- 文件审查：审查合规体系文件
- 访谈：访谈管理层、合规人员、业务人员
- 测试：测试控制点的执行
- 数据分析：分析合规指标数据

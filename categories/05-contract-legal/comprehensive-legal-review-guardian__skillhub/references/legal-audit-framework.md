# 法律审核框架与标准体系

## 一、法律审核的核心框架

### 1.1 风险导向法律审核框架

法律审核采用风险导向的方法——将有限的审核资源集中于最重大的法律风险领域。

**风险导向审核的四个环节：**
1. 风险识别：识别组织面临的各类法律风险
2. 风险评估：评估风险的概率、影响和不可逆性
3. 风险应对：根据评估结果设计审核程序
4. 风险监控：持续监控风险变化

### 1.2 合规体系框架（ISO 37301 + 中国标准）

**合规体系七要素（基于ISO 37301合规管理体系标准）：**

| 要素 | 核心要求 | 审核关注点 |
|------|---------|-----------|
| 领导作用 | 治理机构和最高管理者的承诺与支持 | 最高管理者是否签署合规承诺、是否分配充足资源 |
| 合规方针 | 明确的合规方针与目标 | 合规方针是否发布、是否被员工理解 |
| 组织结构 | 合规职能部门的设立与权限 | 合规部门是否独立、是否有足够权限 |
| 策划 | 风险识别与合规义务梳理 | 是否定期更新风险清单、是否跟踪法律法规变化 |
| 支持 | 资源、能力、意识、沟通、文件化信息 | 是否提供合规培训、是否建立合规信息库 |
| 运行 | 运行控制与外包过程控制 | 关键流程是否有合规控制点、外包是否有合规审查 |
| 绩效评价 | 监视、测量、分析和评价 | 是否有合规KPI、是否定期审计合规体系 |

### 1.3 内部控制与合规体系的关系

**COSO内部控制框架五要素在法律审核中的应用：**

| 要素 | 法律审核关注点 |
|------|-------------|
| 控制环境 | 法务部门地位、合规文化、管理层诚信 |
| 风险评估 | 法律风险识别机制、风险评估方法 |
| 控制活动 | 法律审核流程、合同审批控制、合规检查 |
| 信息与沟通 | 法律风险信息传递、合规培训沟通 |
| 监控活动 | 法律合规监控、内部审计、问题整改 |

## 二、法律审核准则体系

### 2.1 中国法律体系层级

| 层级 | 法律渊源 | 效力等级 | 审核依据权重 |
|------|---------|---------|------------|
| 宪法 | 《宪法》 | 最高 | 根本依据 |
| 法律 | 全国人大及其常委会制定 | 仅次于宪法 | 主要依据 |
| 行政法规 | 国务院制定 | 低于法律 | 重要依据 |
| 地方性法规 | 地方人大制定 | 低于行政法规 | 区域业务依据 |
| 部门规章 | 国务院各部委制定 | 低于行政法规 | 行业业务依据 |
| 地方政府规章 | 地方政府制定 | 低于地方性法规 | 区域业务参考 |
| 司法解释 | 最高法/最高检 | 具有法律效力 | 裁判预测依据 |

### 2.2 民商事法律审核核心依据

**《民法典》七编结构：**
- 总则编：民事主体、民事权利、民事法律行为、代理、诉讼时效
- 物权编：物权变动、所有权、用益物权、担保物权
- 合同编：合同订立、效力、履行、保全、变更转让、终止、违约责任 + 19类典型合同
- 人格权编：生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、隐私权、个人信息保护
- 婚姻家庭编：结婚、家庭关系、离婚、收养
- 继承编：法定继承、遗嘱继承、遗赠
- 侵权责任编：损害赔偿、产品责任、机动车交通事故、医疗损害、环境污染、高度危险、饲养动物、建筑物倒塌

## 三、合规调查程序框架

### 3.1 合规调查的启动标准

**应当启动合规调查的情形：**
- 收到内部/外部举报且举报内容具体可信
- 审计或日常监控发现重大异常
- 监管机构要求调查
- 媒体曝光引发重大质疑
- 离任审计发现重大疑点

### 3.2 合规调查的程序规范

**第一阶段：初步评估**
1. 评估举报/线索的可信度与严重性
2. 确定调查范围与调查团队
3. 制定调查计划与保密措施
4. 评估是否需要保全证据

**第二阶段：证据收集**
1. 文件证据收集：合同、审批记录、财务凭证、通信记录
2. 电子证据收集：系统日志、邮件、即时通讯记录（须合法合规获取）
3. 数据分析：资金流向分析、异常交易识别、关联关系图谱
4. 访谈取证：按从外围到核心的顺序，遵循访谈规范

**第三阶段：调查报告**
1. 客观陈述事实，区分"已证实事实"与"合理怀疑"
2. 分析违规性质、情节与后果
3. 评估对组织的影响
4. 提出纠正建议与防范措施
5. 评估是否需要向监管机构报告

**第四阶段：后续处理**
1. 根据调查结果启动相应级别的纠正程序
2. 追究相关责任人责任（区分恶意程度）
3. 修复违规暴露的合规缺陷
4. 评估违规对组织文化的冲击并启动文化修复

### 3.3 合规调查的底线原则

- **无罪推定**：在证据确凿前，不得预设被调查者有错
- **程序正义**：调查程序须合法合规，不得以非法手段获取证据
- **保密义务**：调查过程与结果须严格保密，保护所有相关人员
- **比例原则**：调查措施须与嫌疑程度相适应，不得过度调查
- **救济保障**：被调查者有权获得陈述和申辩的机会

## 四、法律审核的国际化标准

### 4.1 国际合规标准

| 标准 | 适用范围 | 核心内容 |
|------|---------|---------|
| ISO 37301 | 合规管理体系 | 合规体系七要素、PDCA循环 |
| ISO 37001 | 反贿赂管理体系 | 反贿赂风险评估、控制措施 |
| ISO 27001 | 信息安全管理体系 | 信息安全风险、控制目标 |
| ISO 19600 | 合规管理指南（已被37301替代） | 合规管理指导 |
| OECD指南 | 跨国企业合规 | 跨国企业行为准则 |

### 4.2 跨境法律审核要点

**跨境贸易：**
- 贸易术语选择（INCOTERMS 2020）
- 支付方式风险（信用证、托收、汇付）
- 争议解决条款（法院管辖vs国际仲裁）
- 准据法选择

**跨境投资：**
- 外资准入限制（负面清单）
- 国家安全审查
- 反垄断申报
- 外汇管制

**跨境数据传输：**
- 中国数据出境安全评估
- GDPR跨境传输机制（充分性认定、标准合同条款、约束性企业规则）
- 数据本地化要求

**跨境争议解决：**
- 国际仲裁（ICC、SIAC、HKIAC等）
- 纽约公约下的裁决承认与执行
- 跨境诉讼的管辖与判决承认

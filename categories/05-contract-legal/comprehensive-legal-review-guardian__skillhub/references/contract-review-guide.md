# 合同审核指南

## 一、合同审核的哲学定位

合同审核不是单纯的条款比对，而是对交易关系的守护。每一份合同背后，都是真实的交易关系和利益交换。合同审核的终极目标，是让交易各循其轨（合法有效）、互爱安好（权利义务公平、风险分配合理）。

### 1.1 合同审核的三元认知

**诗心维度**：感受合同背后的真实交易——这笔交易对各方意味着什么？风险分配是否公平？谁处于弱势地位？

**法思维度**：运用法律知识精准识别合同中的法律风险——效力风险、条款缺陷风险、履行风险、救济风险。

**和想象力维度**：在"通过"与"否决"之间创造第三条路——如何修改条款既控制风险又促成交易？如何设计交易结构既合规又高效？

### 1.2 合同审核的聚合-舒展节律

- **聚合**：深入理解交易背景、识别核心风险点、聚焦关键条款
- **舒展**：提出可落地的修改建议、设计替代交易结构、促进交易达成

## 二、合同审核的核心要素

### 2.1 合同效力审核

**主体资格审查：**
- 自然人：是否具有完全民事行为能力
- 法人：是否依法成立、是否存续、法定代表人是否适格
- 非法人组织：是否依法成立、负责人是否适格
- 代理人：是否有有效授权、授权范围是否充分、授权是否在有效期内

**意思表示审查：**
- 是否存在重大误解（对合同性质、对方当事人、标的物品种、质量、规格等的错误认识）
- 是否存在欺诈（故意告知虚假情况或隐瞒真实情况）
- 是否存在胁迫（以给公民及其亲友的生命健康、荣誉、名誉、财产等造成损害相要挟）
- 是否存在显失公平（利用对方处于危困状态、缺乏判断能力等情形）

**内容合法性审查：**
- 合同目的是否合法
- 是否违反法律、行政法规的强制性规定（区分效力性强制性规定与管理性强制性规定）
- 是否违背公序良俗
- 是否以合法形式掩盖非法目的

**形式审查：**
- 法律要求书面形式的是否采用书面形式（如借款合同、保证合同、租赁期限六个月以上的租赁合同）
- 需要登记/备案的是否完成（如不动产抵押登记、专利权质押登记）
- 需要审批的是否获得审批（如外商投资、国有资产转让）

### 2.2 合同条款审核

**核心条款清单（8项必备）：**

| 条款 | 审核要点 | 常见缺陷 |
|------|---------|---------|
| 标的条款 | 标的物描述是否具体明确 | 标的物描述模糊、无法特定化 |
| 数量条款 | 数量是否明确、计量单位是否标准 | 数量约定不明、计量单位不规范 |
| 质量条款 | 质量标准是否明确、验收标准是否可操作 | 质量标准缺失、验收标准不可操作 |
| 价款条款 | 价格是否明确、是否含税、支付方式是否明确 | 价格约定不明、含税情况不明 |
| 履行条款 | 履行期限、地点、方式是否明确 | 履行期限不明、履行地点缺失 |
| 违约责任 | 违约情形是否明确、责任是否对等 | 违约责任缺失、责任明显失衡 |
| 争议解决 | 管辖约定是否有效、仲裁/诉讼选择是否合理 | 管辖约定无效、约定不明 |
| 签署条款 | 签署日期、签署地点、签署人 | 签署日期缺失、签署人无授权 |

**特殊条款审查：**

- **不可抗力条款**：是否明确不可抗力的定义、通知义务、证明责任、后果分担
- **情势变更条款**：是否约定情势变更的认定与处理机制
- **保密条款**：保密信息范围是否明确、保密期限是否合理、违约责任是否明确
- **知识产权条款**：知识产权归属是否明确、许可范围是否清晰、侵权责任是否约定
- **反商业贿赂条款**：是否约定反商业贿赂承诺、违约后果是否明确
- **变更解除条款**：变更解除条件是否明确、程序是否约定
- **通知送达条款**：送达地址是否明确、送达方式是否约定、送达后果是否明确

### 2.3 履行风险评估

**对方履约能力评估：**
- 资信调查：注册资本、经营状况、涉诉情况、信用记录
- 履约历史：是否有违约记录、是否有履行同类合同的经验
- 担保措施：是否有保证、抵押、质押、定金、履约保证金

**履行监控机制评估：**
- 是否设立履行节点监控
- 是否建立预警机制
- 是否有阶段性验收
- 是否有履行证据保全

**救济措施评估：**
- 违约救济是否充分（继续履行、采取补救措施、赔偿损失、支付违约金、解除合同）
- 证据保全是否到位（履行记录、沟通记录、验收记录）
- 担保措施是否有效（担保是否登记、保证是否有效）

## 三、典型合同分类审核要点

### 3.1 买卖合同审核要点

| 审核维度 | 核心关注 |
|---------|---------|
| 标的物交付 | 交付时间、交付地点、交付方式、风险转移时点 |
| 质量标准 | 国家标准/行业标准/企业标准/约定标准、检验期间、异议期 |
| 价款支付 | 支付方式、支付时间、支付条件、发票开具 |
| 所有权转移 | 约定所有权保留条款、动产交付即转移、不动产登记转移 |
| 风险负担 | 风险转移时点（交付前归卖方、交付后归买方） |
| 知识产权 | 知识产权是否随标的物转移、知识产权侵权担保 |
| 售后服务 | 质保期、售后服务范围、响应时间 |

### 3.2 服务合同审核要点

| 审核维度 | 核心关注 |
|---------|---------|
| 服务内容 | 服务范围是否明确、服务标准是否可衡量 |
| 服务期限 | 期限是否明确、续约条件是否约定 |
| 服务费用 | 费用计算方式、调整机制、支付节点 |
| 知识产权 | 服务成果知识产权归属、许可范围 |
| 保密义务 | 保密信息范围、保密期限、违约责任 |
| 服务变更 | 变更程序、变更费用、变更对期限的影响 |
| 验收标准 | 验收标准是否可操作、验收程序、异议处理 |

### 3.3 借款合同审核要点

| 审核维度 | 核心关注 |
|---------|---------|
| 借款金额 | 金额是否明确、币种是否明确 |
| 借款用途 | 用途是否明确、是否限制用途变更 |
| 借款期限 | 期限是否明确、提前还款条件、展期条件 |
| 利率约定 | 利率是否超过法定上限、利率调整机制 |
| 还款方式 | 还款方式（等额本息/等额本金/到期还本付息） |
| 担保措施 | 保证/抵押/质押是否有效设立 |
| 违约责任 | 违约情形、加速到期条款、违约金 |
| 提前到期 | 提前到期触发条件、通知程序 |

### 3.4 租赁合同审核要点

| 审核维度 | 核心关注 |
|---------|---------|
| 租赁物 | 租赁物描述是否具体、状态是否明确 |
| 租赁期限 | 期限是否明确、是否超过法定上限（20年） |
| 租金 | 租金标准、支付方式、调整机制 |
| 押金 | 押金金额是否合理、退还条件、扣除情形 |
| 维修义务 | 维修义务分担是否明确 |
| 转租 | 是否允许转租、转租条件 |
| 优先权 | 承租人优先购买权、优先承租权 |
| 合同终止 | 终止条件、提前终止程序、恢复原状义务 |

### 3.5 保证合同审核要点

| 审核维度 | 核心关注 |
|---------|---------|
| 保证方式 | 一般保证vs连带责任保证（约定不明推定为一般保证） |
| 保证范围 | 主债权、利息、违约金、损害赔偿金、实现债权的费用 |
| 保证期间 | 保证期间是否明确、约定不明的法律后果 |
| 保证人资格 | 保证人是否适格（国家机关、学校、医院等不得为保证人） |
| 独立担保 | 独立担保的效力（国内合同中独立担保效力存争议） |
| 保证变更 | 主合同变更对保证责任的影响 |

### 3.6 劳动合同审核要点

| 审核维度 | 核心关注 |
|---------|---------|
| 合同期限 | 固定期限/无固定期限/以完成一定工作任务为期限 |
| 试用期 | 试用期长度是否合法、试用期工资是否合法 |
| 工作内容 | 岗位描述是否明确、调岗条件是否约定 |
| 劳动报酬 | 工资标准是否合法、工资构成是否明确 |
| 工作时间 | 工时制度是否合法、加班安排是否合规 |
| 社会保险 | 社保缴纳是否约定、缴纳基数是否合法 |
| 竞业限制 | 竞业限制范围是否合理、补偿是否合法、期限是否合法（不超过2年） |
| 服务期 | 培训服务期是否合法、违约金是否合法 |
| 合同解除 | 解除条件是否合法、程序是否合规 |

## 四、典型风险条款库

### 4.1 高风险条款识别

**对己方高风险的条款：**
- 单方违约金过高（超过实际损失30%可能被调整）
- 不可抗力条款缺失或范围过窄
- 争议解决条款约定对己方不利（异地管辖）
- 单方变更/解除权过度（对方可单方变更/解除而无补偿）
- 知识产权条款过度（己方知识产权无偿归对方所有）
- 保密义务不对等（己方保密义务重、对方保密义务轻）
- 赔偿责任无上限（己方赔偿责任无封顶）

**对交易公平性高风险的条款：**
- 格式条款中的免责条款（可能因未履行提示说明义务而无效）
- 显失公平的条款（利用优势地位强加不合理条件）
- 排除对方主要权利的条款（可能无效）

### 4.2 条款修改建议库

**违约责任条款修改：**
- 原条款：一方违约，应赔偿对方一切损失
- 修改建议：明确违约情形、赔偿范围、赔偿上限、举证责任

**争议解决条款修改：**
- 原条款：争议提交原告所在地法院管辖
- 修改建议：争议提交[己方所在地/合同履行地]法院管辖；或争议提交[某仲裁机构]仲裁

**知识产权条款修改：**
- 原条款：合同履行过程中产生的所有知识产权归甲方所有
- 修改建议：区分背景知识产权与前景知识产权；前景知识产权按贡献分配或约定归属；一方使用对方知识产权须获得许可

**保密条款修改：**
- 原条款：双方对合同内容保密
- 修改建议：明确保密信息范围、保密期限、保密例外情形、违约责任

## 五、合同审核的输出

### 5.1 合同审核意见

合同审核完成后，输出结构化的审核意见：

```
## 合同审核意见

**合同名称**：[合同名称]
**审核日期**：[日期]
**审核人**：[审核人]
**总体结论**：[通过/附条件通过/需修改后复审/不予通过]

### 一、合同效力评估
[合同效力的评估结论]

### 二、核心条款审核
| 条款 | 审核结论 | 风险点 | 修改建议 |
|------|---------|--------|---------|
| 标的条款 | ✅/⚠️/🔴 | ... | ... |
| 价款条款 | ✅/⚠️/🔴 | ... | ... |
| ... | ... | ... | ... |

### 三、风险提示
[需要重点关注的风险及应对建议]

### 四、修改建议
[具体的条款修改建议]

### 五、交易结构建议
[如有必要，提供交易结构优化建议]
```

### 5.2 合同审核清单

提供标准化的合同审核清单，确保审核的系统性：
- 效力要素清单（主体、意思、内容、形式）
- 核心条款清单（8项必备条款）
- 特殊条款清单（根据合同类型）
- 履行风险清单（履约能力、监控、救济）

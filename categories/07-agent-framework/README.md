## 安装

将本分类下对应的技能文件夹整体复制到 WorkBuddy 用户级技能目录：

```bash
# Windows
xcopy "%USERPROFILE%\.workbuddy\skills"  # 放入对应子文件夹
# 或直接把某个技能文件夹复制到 (Windows 示例):
C:\Users\<你>\.workbuddy\skills\<技能名>
```

放入后重启 WorkBuddy 即可在对话中触发。

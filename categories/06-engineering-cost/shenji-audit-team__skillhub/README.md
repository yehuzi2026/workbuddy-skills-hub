# 工程造价审计AI助手

工程造价审计专家天团：**审清**（主理人）+ **结算清 / 审计明 / 索赔通 / 清单准 / 指标衡** 五角色协同，覆盖清单计价 → 结算审核 → 造价审计 → 索赔 → 指标对标 → 全过程造价控制的全流程。

## 形态

- **团队形态**（`expertType: team`）：在「我的专家」本地多角色真·协同，入口 `.codebuddy-plugin/plugin.json` + `agents/*.md`。
- **单代理形态**：作为单一角色独立运行 / 分发，入口 `skills/<角色>/SKILL.md`（由 `agents/` 同源派生，冲突时以 `agents/` 为准）。

## 角色

| 角色 | 职责 | 定义 |
|---|---|---|
| 审清 | 造价审计总指挥（派单 / 汇总 / 门禁终检） | `agents/cost-audit-team-team-lead.md` |
| 结算清 | 结算审核师 | `agents/audit-settlement.md` |
| 审计明 | 造价审计师 | `agents/audit-auditor.md` |
| 索赔通 | 索赔分析师 | `agents/audit-claim.md` |
| 清单准 | 清单计价师 | `agents/audit-pricer.md` |
| 指标衡 | 指标分析师 | `agents/audit-index.md` |

## 核心能力

- **真实计算引擎** `calc_engine.py`：24 个函数（`--list` 可查），`--selftest` 99 项断言全过。覆盖调值公式、材料风险幅度三档调整（含多期用量加权）、工程量偏差 ±15% 调价、清单组价（可引用当地真实价格）、结算总价、审减额与明细、**审减归因（量差+价差=审减额）**、**勾稽校验**、**检查范围方案（抓大放小+覆盖率，非统计抽样）**、预付款扣回、质保金、逾期利息、索赔时差与最终报告时限、单方 / 含量指标对标。
- **离线权威检索** `authority_search.py` + `references/standards/规范数据库.json`（31 条条款，每条带 `std_ref` / `validity` / `applies_to`）。按分词打分匹配，自然语句（如「材料价格风险幅度」）也能命中，命中退出码 0、库外退出码 1 并强制给出「库外降级」声明。
- **统一输出门禁** `references/search/gate.py`：片段级判定，拦截「无出处数字 / 金额只标条文无来源 / 模糊措辞+数字 / 编码损坏」；WARN 提示「价格未声明来源 / 缺实算证据」；审计留痕 `gate_log.jsonl`。
- **文件解析与当地价格接入** `ingest.py`：xlsx / xlsm / csv / pdf 原生解析；`--build-rates` 把当地信息价 / 费用定额表转成 `references/data/local_rates.json`（缺价时组价 fail-closed 报错，绝不静默按 0 计）；`--hash` 算导出文件的 SHA-256 / MD5 指纹（电子数据校验值登记，`--hash --expect` 使用前复算比对，不一致退出码 1）。
- **对量分析** `reconcile.py`：把送审与审定两版明细（xlsx / xlsm / csv）按项目编码逐项比对，自动拆出**量差 / 价差 / 漏项 / 增项**并做四项闭合校验（量差+价差+漏项+增项 ≡ 总差额），输出差异明细 xlsx + 分析报告 md（自带门禁自检）。
- **结构化交付** `deliverable.py`：**9 类**交付物（表格 xlsx + 报告 md）——结算审核、造价审计、索赔分析、指标分析、**审计底稿**、**审计实施方案（检查范围）**、**资料索取清单（PBC）**、**问题整改台账**、**争议事项台账**；报告结论句自带数据来源并可过门禁；`python deliverable.py` 一键产出 9 类样例并逐份自检。
- **审计作业知识库**：`references/knowledge/06_审计底稿与证据链.md`（底稿九要素 / 证据分级 / 三级复核 / 勾稽与归因验算 / 审计范围限制披露 / 台账闭环）、`07_签证与变更审查要点.md`（变更五步 / 签证有效性要件 / 高频虚报手法 / 索赔三关）。
- **审计项目成套模板** `project_template.py`：一条命令把一个项目变成**一卷可归档的审计档案**——六卷固定目录（审前调查 / 审计实施方案 / 资料交接 / 底稿与证据 / 问题与争议 / 报告与归档）+ 00 项目索引，共 **30 份文件**（含 xlsx）；除底稿与台账外，还有**现场取证记录单、抽样见证记录、电子数据取数说明、三级复核意见记录表、征求意见与沟通记录、期后事项与追溯调整记录、证据附件页码索引、审计日记与工作记录、外聘人员与回避记录、整改回访记录**十份过程留痕件；缺数据之处一律留「（待填）」，**绝不代填**；生成后逐份过门禁。填不出来的先空着，补全后重跑同一条命令即可整体刷新。
- **证据完整性与过程留痕**：成套档案内置**证据附件页码索引**（「报告金额 → 底稿索引 → 附件页码」三步可查；页数缺口处其后页码一律留「（待填）」、不跳页累加）、**电子数据校验值登记**（`ingest.py --hash` 算 SHA-256 / MD5，使用前复算比对，不一致即拦截）、**审计日记与工作记录**、**外聘人员与回避记录**、**整改回访记录**（销号须有金额 / 制度 / 程序三类实质性证据）。
- **多项目总台账** `project_template.py --portfolio <目录>`：扫描目录下所有项目档案的 `项目信息.json`，汇总成审计组总台账（xlsx + md）：项目 / 阶段 / 送审与审定 / 审减额与审减率 / 问题数与未销号数 / 争议数；缺项留「（待填）」、合计只累计有值的行。
- **问题定性与依据配对** `issue_pair.py`：问题描述或定性 → 规范数据库条款（带标准号、条款、效力、适用条件与要点）+ 常见处理 + 证据要求；未命中会**如实说未命中**并转向条文检索，绝不编条款。
- **法规时效巡检** `staleness_check.py`：对法规注册表与规范数据库核校日做超期告警。
- **内容自检** `content_check.py`：一键校验全包完整性（编码/JSON/语法/截断）+ **文档/代码/配置一致性**（文档引用的 `--func` 与脚本必须真实存在、plugin.json 角色与工具必须存在、单代理 SKILL 必须与 agent 定义逐字同源、知识库索引必须收录全部文件、项目信息模板必须与代码同源、成套模板构件必须真实接线、成套档案文件数说明必须与实现同步、每个工具必须被至少一份角色定义提到）+ **逐题复算题库计算题**（`--quick` 只查完整性与一致性）。
- **题库与案例**：`question_bank/`（52 题）+ `case_library/`（5 个可复算教学案例）。

## 快速开始

在「我的专家」打开本团，发送：`帮我梳理工程造价审计AI助手的核心工作流`

带文件更高效：直接附合同 / 图纸 / 结算书 / 签证单，对应角色先 Read 再答。

**本助手是造价审计作业助手（不是练习题库）**，按活儿找入口：

| 你要做的事 | 直接这样说 | 顺带产出 |
|---|---|---|
| 审竣工结算 | 「审这份竣工结算，给出审定价、审减额与原因」（附结算书 / 合同） | 结算审核对比表 + 审核报告 |
| 两版数据对量 | 「这两张表是对量，找出量差、价差和漏项」（附送审 / 审定两个文件） | 对量差异明细 + 分析报告 |
| 独立审计 | 「对这个项目做竣工决算审计，看超概与证据链」 | 造价审计报告 + 审计底稿 |
| 定检查范围 | 「这 20 个分项帮我定必查和抽查范围（要覆盖率）」 | 审计实施方案（检查范围） |
| 要资料 | 「出一份资料索取清单，我要发给施工单位」 | 资料索取清单（PBC） |
| 追整改 / 有争议 | 「把这些问题建成整改台账 / 这几项有争议建个台账」 | 问题整改台账 / 争议事项台账 |
| 索赔判定 | 「工期延误能索赔吗，能赔多少」 | 索赔分析报告 + 证据清单 |
| 指标对标 | 「单方造价合理吗」 | 造价指标分析表 + 对标报告 |
| **开一个新的审计项目** | 「我要开一个新项目，先把整套审计档案建起来」 | 六卷成套档案 + 项目索引 |
| **推进某一份档案** | 「把审计实施方案补全 / 问题台账更新一下」 | 对应卷内文件整体刷新 |
| **问题定性拿不准依据** | 「这个问题定性该引哪条」 | 建议依据 + 常见处理 + 证据要求 |
| **多个项目要总览** | 「手上几个项目出份总台账」 | 多项目总台账（xlsx + md） |
| **电子数据要登记校验值** | 「这批导出的台账要登记指纹，以后用之前要对一遍」 | SHA-256 / MD5 校验值 + 复算比对 |
| **记审计日记 / 做整改回访** | 「把这几天的现场工作记进日记」「这几个问题做回访核实能否销号」 | 审计日记与工作记录 / 整改回访记录 |

## 题库与章节专项练习包（辅助功能，非主线）

`question_bank/questions.json`：**52 题 = 28 选择 + 18 计算 + 6 实操交付**。计算题答案由 `calc_engine.py` 现场实算生成（题目内含可复现 command）。
`question_bank/chapter_packs.json` 按工作阶段（章节）拆分，供按章刷题：

| 章节 | 题数 | 说明 |
|---|---|---|
| 清单计价 | 10 | 清单规范、综合单价、组价与漏项 |
| 竣工结算审核 | 12 | 报送与审定、审减、调差、预付款与质保金 |
| 工程造价审计 | 7 | 全过程 / 跟踪审计、偏差与超概、决算 |
| 工程索赔 | 9 | 索赔三要素、时限、工期与费用 |
| 指标与数据库 | 7 | 单方指标、含量指标、对标可比性 |
| 全过程造价控制 | 7 | 估算、概算、预算、结算、决算闭环 |

**合计 52 题**。全部标注「练习(非官方真题)」，详见 `question_bank/真题来源声明.md`。

## 重要声明

> 本助手所有造价数据、指标、组价、费率、对标结果均为 **【AI 参考值】**，**非官方审定价**。
> 内置库只含「计价规则 / 法规条文」，**不含任何材料价 / 人工单价 / 机械台班 / 费率等价格数字**；价格须由用户导入当地公布数据。
> **计价依据以合同约定为准**：合同约定按 GB 50500-2013 执行的既有项目仍按合同履行。
> 真实工程审计须以真实项目数据与当地造价管理部门最新公布数据为准，并由注册造价工程师签章确认。

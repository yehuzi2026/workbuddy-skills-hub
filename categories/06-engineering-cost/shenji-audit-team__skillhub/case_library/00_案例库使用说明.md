# 案例库使用说明（必读）

> **性质声明**：本目录案例均为**脱敏教学案例**——数据由本团构造或用公开规则推演，用于演示"怎么算、依据什么、坑在哪"，
> **不是某个真实项目的实例，也不代表任何特定项目的实际审定价**。请勿在正式文件中引用本库数据作为项目依据。
> 每个案例都给出可复算的引擎命令；数字一律由命令现场复现，不得手工改写。

## 用法
1. 先看"关键问题"，判断与你手上的问题是否同类；
2. 照"复算命令"跑一遍，理解计算口径；
3. 重点看"易错点"，这是审计中最常被忽略或被利用的地方；
4. 需要用于具体项目时，把构造数据换成用户提供的真实数据后重新实算。

# 案例四 · 审减率预警线与审减明细（脱敏教学案例）

## 场景（构造数据）
某政府投资房建项目竣工结算审核：
- 报送价 1200 万元，审定价 1080 万元；
- 委托合同约定：审减率超过 10% 时启动复核程序；
- 审减明细：工程量核减 60 万元、单价核减 40 万元、取费核减 20 万元。

## 关键问题
1. 审减额与审减率是多少？是否超预警线？
2. 审减明细合计与审减额是否一致（反向验算）？
3. 审减率等于 10% 时怎么表述才准确？

## 依据
- 审减额 = 报送价 − 审定价；审减率 = 审减额 ÷ 报送价；
- 审减率预警线（本例 10%）属**委托合同约定**，不是规范强制阈值；
- 禁止只给审减率不给明细：须逐项列明审减原因与对应条款。

## 复算命令
```bash
python calc_engine.py --func audit_reduction_detail --submit 1200 --approved 1080 --details "工程量核减:60;单价核减:40;取费核减:20"
python calc_engine.py --func audit_reduction_detail --submit 1200 --approved 1068 --details "工程量核减:100"
```

## 预期输出（引擎实算）
- 审减额 **120 万元**、审减率 **10.00%**；`超预警线 = false`，提示"审减率恰等于预警线，未超限，须在报告中明确表述"；
- 明细合计 120 万元 → `明细校验 = OK`；反向验算 1080 + 120 = 1200 万元 ✓；
- 第二个命令（审减 132 万元、审减率 11.00%）：明细只填 100 万元 → 校验报警"明细合计与审减额不一致，须逐项核对"。

## 易错点
1. 把 10.00% 写成"超预警线"或"接近预警线"（边界表述必须精确）；
2. 只报审减率不报明细，导致无法判断审减是否合理；
3. 明细与总额对不上仍直接出报告（必须反向验算）；
4. 把审减率高低等同于报送方责任。

## 启示
审减结论的可用性取决于"明细 + 依据 + 反向验算"三件套，而不是一个百分数。

# 案例二 · 材料价格风险幅度调差（脱敏教学案例）

## 场景（构造数据）
某工程钢筋（HRB400 Φ20 内）：
- 基准单价 3000 元/t；
- 投标报价 2950 元/t（**低于**基准价 50 元/t）；
- 施工期信息价 3200 元/t；
- 合同约定风险幅度 ±5%；用量 1000 t。
问：结算单价与调差合价是多少？

## 关键问题
1. 涨价应以"投标价"还是"基准价"为比较基础？
2. 幅度内由谁承担？超出部分怎么算？
3. 若投标报价高于基准价（例如 3200 > 3000），算法有什么不同？

## 依据
材料价格风险幅度三档规则（GB 50500-2013 附录 A / GB/T 50500-2024 对应条文，⚠ 条款号以官方原文为准）：
- 投标价 **<** 基准价：**涨价以基准价为基础**超幅度调增；跌价以投标价为基础超幅度调减；
- 投标价 **>** 基准价：**跌价以基准价为基础**超幅度调减；涨价以投标价为基础超幅度调增；
- 投标价 **=** 基准价：涨跌均以基准价为基础超幅度调整。
仅"超出风险幅度的部分"据实调整，幅度内不调（结算单价 = 投标价）。

## 复算命令
```bash
python calc_engine.py --func adjust_info --current 3200 --base 3000 --bid 2950 --risk 5 --qty 1000
python calc_engine.py --func adjust_info --current 3500 --base 3000 --bid 3200 --risk 5 --qty 100
```

## 预期输出（引擎实算）
- 情形一（投标价 2950 < 基准价 3000）：调增判定上限 = 3000×(1+5%) = 3150 元/t；施工期价 3200 元/t 超上限，超出部分 = 3200 − 3150 = 50 元/t；
  结算单价 = 2950 + 50 = **3000 元/t**；调差合价 = 50 × 1000 = **50000 元**。
- 情形二（投标价 3200 > 基准价 3000）：调增判定上限以**投标价**为基础 = 3200×1.05 = 3360 元/t；施工期价 3500 超上限，超出部分 = 140 元/t；结算单价 = 3200 + 140 = **3340 元/t**。

## 易错点
1. 一律用"基准价×(1+幅度)"判断超限——投标价高于基准价时应改用投标价为判断基础，否则算错方向；
2. 把幅度内部分也调增（正确做法：只调超出幅度部分，幅度内由承包人承担）；
3. 把"调值公式法"与"造价信息调整法"混用（适用方法按合同约定）；
4. 只算单价不算量：调差合价 = 调差单价 × 工程量，工程量口径须与清单一致。

## 启示
材料调差是结算争议高发区，核心是"先分清投标价与基准价的关系，再确定比较基准与幅度口径"。

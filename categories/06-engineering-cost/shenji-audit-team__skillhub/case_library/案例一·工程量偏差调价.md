# 案例一 · 工程量偏差超 ±15% 的调价（脱敏教学案例）

## 场景（构造数据）
某市政管道工程，清单工程量 1000 m³，综合单价 380 元/m³（已标价工程量清单）。
竣工计量实际完成 1300 m³。合同约定：工程量偏差超过 ±15% 时，超出部分的综合单价按原单价的 90% 计取（调低），15% 以内按原单价。

## 关键问题
1. 偏差率是多少？是否触发调价？
2. 调价后合价是多少？与原合价差多少？
3. 如果实际量是 1150 m³（恰为 +15%），要不要调价？

## 依据
- 工程量偏差 =（实际工程量 − 清单工程量）/ 清单工程量；
- 偏差超过 ±15% 时可调价：增加超 15% 的部分单价调低；减少超 15% 的剩余部分单价调高（GB 50500-2013 第 9.6.2 条 / GB/T 50500-2024 对应条文，⚠ 条款号以官方原文为准）；
- **±15% 本身不触发调整**（边界值不调）。

## 复算命令
```bash
python calc_engine.py --func qty_deviation_adjust --list_qty 1000 --actual_qty 1300 --unit_price 380 --over_factor 0.9
python calc_engine.py --func qty_deviation_adjust --list_qty 1000 --actual_qty 1150 --unit_price 380
```

## 预期输出（引擎实算）
- 偏差率 30.00%，触发调价；
- 原合价 494000 元；调整后合价 488300 元（其中 1150 m³ 按 380 元/m³、150 m³ 按 342 元/m³）；
- 增减额 −5700 元；
- 实际量 1150 m³ 时：偏差率恰为 15.00%，**不调价**，合价 437000 元。

## 易错点
1. 把"超出 15% 的部分"算成"全部工程量都调价"（正确算法只调 150 m³）；
2. 边界值当成超限（15.00% 不调价）；
3. 调价幅度（90%）合同没约定时自行取值——必须先按合同程序协商确认，不得由审核方单方取值；
4. 不区分合同类型：总价合同通常不按工程量偏差调价，须先看合同类型与约定。

## 启示
量差调价是结算审核的第一大审减来源，核心是"阈值边界 + 调价范围 + 幅度依据"三件事都要有出处。

# 案例五 · 单方指标对标与口径（脱敏教学案例）

## 场景（构造数据）
某住宅项目：总造价 12000 万元，建筑面积 10000 ㎡；
对标基准：同类住宅同业均值 10000 元/㎡、本单位限额指标 11000 元/㎡；
含量指标：钢筋 500 t、混凝土 3000 m³。

## 关键问题
1. 单方指标是多少（元/㎡ 与 万元/㎡ 两种表述）？
2. 相对两个基准的偏差率各是多少？方向如何？
3. 这个偏差能直接判定"造价偏高"吗？

## 依据
- 单方指标 = 总造价 ÷ 建筑面积；含量指标 = 工程量 ÷ 建筑面积；
- 偏差率 =（本项目指标 − 标杆指标）÷ 标杆指标，正为高于标杆；
- 对标必须同业态、同口径、同时点；面积口径（建筑/使用/结构）必须写明。

## 复算命令
```bash
python calc_engine.py --func index_metrics --total_cost 12000 --area 10000 --benchmark 1.0 --area_caliber "建筑面积" --quantities "钢筋:500;混凝土:3000"
python calc_engine.py --func benchmark_index --total_cost 12000 --area 10000 --benchmarks "同业均值:1.0;限额指标:1.1"
```

## 预期输出（引擎实算）
- 单方指标 **1.2 万元/㎡ = 12000 元/㎡**；
- 对同业均值（1.0 万元/㎡）偏差 **+20.00%**（高于标杆）；对限额指标（1.1 万元/㎡）偏差 **+9.09%**；
- 含量指标：钢筋 0.05 t/㎡、混凝土 0.30 m³/㎡。

## 易错点
1. 面积口径未说明（建筑面积与使用面积可差 15%~25%，结论会完全不同）；
2. 拿含精装指标与不含精装指标比较、含地下与不含地下比较；
3. 样本不足（1~2 个项目）就下"明显偏高"的确定性结论；
4. 跨年对比未做价格水平换算；
5. 把经验指标区间当成强制标准或审定价依据。

## 启示
指标的作用是"提示异常、指向核查方向"，不是"直接下结论"。偏差显著时，第一步永远是核查口径，第二步才是判断设计或成本问题。

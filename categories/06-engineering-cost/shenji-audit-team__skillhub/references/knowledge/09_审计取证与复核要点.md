# 09 审计取证与复核要点

> 适用角色：审计明（造价审计师）、结算清（结算审核师）、审清（主理人）。
> 本文解决一个问题：**结论是怎么"取得"的、复核是怎么"留痕"的**——只有「事实 + 条款 + 证据」三件齐备，一项审计发现才算坐实。

## 一、取证三原则

1. **两人及以上、全程记录**：记录取证时间、地点、对象、方式与在场人；单人取证、事后回忆的记录不具有证明力；
2. **签认为要**：取证记录须由被取证方或第三方见证人签认；对方拒绝签认的，须在记录中写明并说明原因，不得留空；
3. **编号归档**：原始资料按「底稿索引 + 顺序号」编号（如 `W-01-1` 为 W-01 号底稿的第 1 项证据），可定位到具体文件与页码；
4. **补记须注明**：不得事后补记而不注明；确需补记的，注明补记时间与原因。

## 二、证据形式与强度

| 证据形式 | 强度 | 使用限制 |
|---|---|---|
| 双方书面确认件、经核验的原件 | 强 | 可直接支撑结论 |
| 单方记录 + 第三方佐证（监理记录、影像、往来函件） | 中 | 可支撑，但需交叉印证 |
| 口头说明、事后回忆、无签认的复印件 | 弱 | **不得单独支撑金额结论**，只能列入待核事项 |

- 证据链查四点：**时间链、主体链、数量链、金额链**——四点不闭合的，先补证据再谈结论。

## 三、抽样见证（工程审计常用口径）

- 检查范围（必查 / 抽中 / 未覆盖）由 `calc_engine.sample_plan` 按「抓大放小 + 覆盖率控制」实算，属经验判断型抽样，**不是统计抽样**，不得对外表述为统计抽样结论；
- 抽中样本的**选取方法与理由**必须记录：顺序抽样 / 大额优先 / 随机数 / 专家判断；
- 抽样过程须有**见证人在场并签认**；
- 实际检查结果与送审资料不一致的，须**扩大样本或追加程序**并记录；
- 未覆盖项不代表无风险：需评估是否追加程序，或在报告中**声明审计范围受限**及其影响。

## 四、电子数据取数

1. **记录取数要素**：数据源系统、取数方式（系统导出 / 只读账号查询 / 对方提供）、取数时间与经办人；
2. **完整性校验**：当年记录数比对、金额合计比对、期间与筛选条件复述；校验不通过的数据不得使用；
3. **不改原始数据**：导出文件只读保存，登记校验信息（记录数 / 合计金额 / 导出时间）；
4. **合规使用**：涉及个人信息或商业秘密的数据，按委托约定范围取用，不得外传。

## 五、三级复核

- 层级：**审计员自校 → 主审复核 → 项目负责人签发**；三级缺一不得对外出具；
- 复核意见须**具体到索引号 / 金额 / 依据 / 证据**，只写「已复核」「同意」不算复核意见；
- 复核提出的问题须在「整改 / 落实情况」栏**闭环**；
- 复核要点清单：① 关键金额复算；② 依据可追溯（含**合同约定的计价依据版本**）；③ 证据链是否闭合；④ 单位口径是否一致；⑤ 报告金额能否指回底稿索引；⑥ 输出门禁放行与拦截留痕是否齐全。

## 六、沟通与征求意见

- 征求意见稿送达后须给**合理反馈期限**，逐条记录反馈意见；
- 反馈意见须**逐条答复**：采纳 / 部分采纳 / 不采纳，不采纳的写明理由与依据；
- **不得以「已沟通」「已解释」代替书面记录**；送达方式、日期、签收人须留痕；
- 沟通不影响无争议部分的处理，也不得以沟通未完成为由搁置全部结论。

## 七、期后事项与追溯调整

- 审定基准日之后至报告签发前发现的事项，须评估是否影响审定数与报告意见；
- 处理方式三选一：**调整**（影响审定数，重新计算）/ **披露**（影响但不调整，在报告中说明）/ **不处理**（不影响或证据不足，写明理由）；
- 已出具结论需调整的，须写明调整前后金额与理由，不得留空、不得隐瞒。

## 八、复核最常挑出来的 10 个缺陷（自检用）

1. 报告金额指不回底稿索引（或索引跳号、一号多项）；
2. 依据只写条文、没写**计价依据版本**与合同约定；
3. 单位口径混用（元 / 万元、面积口径、材料单位）；
4. 证据只有复印件、无签认，或引用「口头说明」；
5. 抽样没有方法说明、没有见证人；
6. 电子取数没有完整性校验（记录数 / 金额合计）；
7. 复核记录只写「同意」，无具体意见、无闭环；
8. 被审计单位反馈意见没有逐条答复；
9. 期后事项没有记录（报告日后拿到的新证据不见了）；
10. 门禁留痕缺失，或未过门禁的内容已对外发出。

# 07 签证、变更与索赔审查要点

> 适用角色：结算清（结算审核师）、索赔通（索赔分析师）、审计明（造价审计师）。
> 这是结算审减最集中的一个领域：**三类事项的计价方式不同，重复计取是最高频的审减点。**

## 一、三者边界（先分清，再谈钱）

| 事项 | 触发原因 | 计价特点 | 关键审查点 |
|---|---|---|---|
| **变更** | 设计/方案对合同范围内工作的修改 | 有适用单价从适用单价；无适用单价另行组价 | 变更程序与权限、是否重复计取 |
| **签证** | 现场实际发生、合同外的事实与费用 | 按实计量 + 约定或认价单价 | 签认手续与事实真实性 |
| **索赔** | 非己方责任的违约或风险事件造成损失 | 按实际损失 / 约定标准补偿 | 时限、责任归属、与变更是否重复 |

> ⚠️ 若合同把"变更"与"签证"混用，以**合同约定的定义**为准，并在报告中写明所采口径。

## 二、变更审查五步法

1. **权**：谁有权发变更指令（建设单位代表 / 设计单位 / 监理），有无越权指令；
2. **序**：是否履行事前审批；事后补办的变更须核实真实性并说明程序瑕疵；
3. **重**：变更内容是否已包含在原合同价、已标价工程量清单或另一份签证中（**重复性检查**）；
4. **价**：变更计价口径——有适用单价从其单价；类似单价可参照；无适用单价须重新组价并附组价过程（人工/材料/机械/管理费/利润/规费税金）；
5. **连**：变更对措施费、工期、其他费用的连带影响是否已计取或被重复计取。

## 三、签证有效性要件（逐项打勾，缺一项即须补强）

- [ ] 事由明确、部位可指认（图号 / 轴线 / 桩号 / 楼层）
- [ ] 工程量有计算式与草图/影像可复核，不是孤立的"一个数"
- [ ] 双方授权代表签字 + 单位盖章（缺一方即降级为"中/弱证据"）
- [ ] 时间与监理日志、施工日志、材料进场记录一致（无倒签迹象）
- [ ] 未包含在合同价、已标价清单或其他签证中
- [ ] 计价方式明确：合同单价 / 认价单 / 当地信息价 / 重新组价（须附来源）
- [ ] 编号连续、与结算书索引对应

## 四、高频虚报手法与审计动作

| 手法 | 表现 | 审计动作 |
|---|---|---|
| 事后集中补签 | 同一日期批量签认跨数月事项 | 比对监理日志、施工日志、影像与材料进场记录 |
| 重复计价 | 变更内容已含在清单综合单价内，又单独签证 | 逐项对照原清单综合单价的工作内容 |
| 量价不符 | 签证数量大于计量/领料记录 | 以领料单、磅单、进场记录倒轧 |
| 单价虚高 | 无认价单却按高价计取 | 查认价单、同期当地信息价、复核组价过程 |
| 措施费重复 | 变更另计脚手架、垂直运输、临时设施 | 检查措施费是否已按包干/总额计取 |
| 甲供材重复 | 甲供材料又进入综合单价 | 核对甲供材台账与扣抵金额 |
| 工期"批发"签证 | 签证工期但无关键线路分析 | 用总时差/关键线路判定可顺延工期 |
| 暂列金额滥用 | 暂列金额无审批即用于新增内容 | 核审批权限与使用范围，未使用部分须扣回 |
| 暂估价未替换 | 暂估价项目未按实替换即结算 | 要求提供招标/询价/认价资料后替换 |

## 五、索赔审查三关

1. **理由关**：事件责任不在承包人（发包人风险、不可抗力、第三方原因、非承包人原因的工程变更）；
2. **时限关**：是否在约定期限内提出意向通知与最终索赔报告（合同常见约定为 28 天，⚠️ 具体以合同/示范文本约定为准，不得一概而论）；
   `python calc_engine.py --func delay_claim --event_date 2025-05-01 --claim_date 2025-05-20 --notice_days 28`
   （该函数同时输出时效判定、可索赔工期与费用索赔额；加 `--event_end_date` 可一并算出最终索赔报告截止日）
3. **计算关**：
   - 工期：延误天数 − 总时差 = 可索赔工期（**超出总时差才影响工期**）
     `python calc_engine.py --func delay_claim --delay_days ... --total_float ...`
     `python calc_engine.py --func delay_extension --delay_days 40 --total_float 10 --final_report_days 28`
   - 费用：窝工损失 = 人数 × 天数 × 约定单价；不得与变更价款、措施费重复计取。
     `python calc_engine.py --func claim_amount --items "..."`

## 六、措施费、暂列金额与计日工

- **措施费**：单价措施项目按量计价，总价措施项目按合同约定（包干 / 按实 / 按费率）；变更是否引起措施费调整须按合同判断，不得默认"变了就加钱"。
- **暂列金额**：由发包人掌握使用，用于合同约定范围外的新增事项；**未使用部分须扣回**，不得直接归承包人。
- **暂估价**：属必然发生的材料/设备/专业工程，须按约定程序（招标、询价、认价）确定实际价格后替换。
- **计日工**：须有现场签证确认的用工、用料记录（工时/台班/材料量），单价按已标价清单计日工表。

## 七、审查产出与留痕

- 每一项变更/签证/索赔，都对应一份底稿（索引号 + 证据 + 计算式 + 结论）：见 `06_审计底稿与证据链.md`。
- 有争议的挂 `dispute_register`；确定的问题挂 `issue_register` 跟踪整改。
- 涉及金额的结论必须能过输出门禁：金额须有数据来源或计算式，只标条文不构成金额依据。

# 01 清单与计价

## 一、清单计价构成（不可缺项）
单位工程造价 = 分部分项工程费（Σ 工程量 × 综合单价）+ 措施项目费 + 其他项目费（暂列金额 / 暂估价 / 计日工 / 总承包服务费）+ 规费 + 税金。

## 二、分部分项清单的"五要素"
项目编码、项目名称、项目特征、计量单位、工程量。**项目特征决定组价**：
- 特征描述不清楚 → 投标人低价报、结算时高索赔；这是清单编制最常见的风险点。
- 特征与图纸不符 → 属于项目特征描述不符，应按实际特征重新确定综合单价（可调价情形之一）。
- 计量单位必须与计价依据（定额/计价标准）一致，否则无法正确组价。

## 三、综合单价的构成
综合单价 = 人工费 + 材料费 + 施工机具使用费 + 企业管理费 + 利润 + 一定范围内的风险费用。
- 管理与利润一般以（人工+材料+机械）或人工费为基数计取，取费基数必须与合同/计价办法一致。
- 风险费用范围由合同约定；约定不明的，不得单方扩大或缩小。
- 综合单价**不含**规费和税金（这两项在单位工程造价层面计取）。

## 四、措施项目费
- 可计量措施（如脚手架、模板、垂直运输、超高施工增加、大型机械进出场）按量计价；
- 不可计量措施（安全文明施工、夜间施工、二次搬运、冬雨季施工、已完工程保护）按项计价；
- **安全文明施工费属不可竞争费用**，必须按规定标准计取，不得作为让利内容。

## 五、招标控制价
- 应据招标文件、清单、施工图、现行计价依据与市场价格编制并随招标文件公布，**不得只公布总价**；
- 不得上浮或下调（不得"下浮招标控制价"来变相压价）；
- 投标人对控制价有异议的，应在招标文件/地方规定期限内（常见为公布后 5 日内）提出。

## 六、常见编制与计价风险（清单准重点）
1. 漏项（清单没列但图纸有）→ 结算时按清单缺项处理，需重新组价；
2. 特征描述歧义 → 计价口径无法唯一确定；
3. 措施费与施工方案不匹配（方案里有、清单里没有）；
4. 暂列金额/暂估价被当成确定价直接计入总价；
5. 计量单位、含税/除税口径前后不一致；
6. 不可竞争费用（安全文明施工费、规费、税金）被让利。

## 七、工具
- 组价：`calc_engine.py --func compose_price`（人材机 + 管理费 + 利润 + 风险 + 可选税金）；
- 引用当地真实价格组价：`--func compose_price_from_rates --materials "材料名:用量" --rates_file references/data/local_rates.json`；
- 合价：`--func list_total --items "工程量:单价;..."`；
- 单位工程造价汇总：`--func project_total --fbfx ... --measures ... --others ... --gov_fee ... --tax_rate ...`。

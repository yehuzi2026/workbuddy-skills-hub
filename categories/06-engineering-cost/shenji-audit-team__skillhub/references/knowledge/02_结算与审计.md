# 02 结算与审计

## 一、竣工结算程序与时限
1. 承包人按约定期限（合同常见约定为竣工后 28 天内）提交竣工结算文件；
2. 发包人按工程规模在 20 / 30 / 45 / 60 天档次内核对并提出意见（以合同、地方规定与官方原文为准）；
3. 双方核对、达成一致后签认（审定）；
4. 发包人按约定支付；逾期支付应付利息。
> 实务要点：逾期未答复是否"视为认可"，须结合合同约定与司法解释判断，不得一概而论。

## 二、审减三段法（先量 → 再价 → 后费）
1. **查量**：重复计量、虚增工程量、超竣工图范围、变更已含在清单内又重复计取；
2. **查价**：综合单价与投标单价不符、擅自改变组价、材料价未按约定风险幅度调整、暂估价未按实替换；
3. **查费**：取费基数错、费率套用错误、规费税金漏计或多计、不可竞争费用被让利。
> 审减必须**逐项列明原因 + 对应依据（合同条款/签证/计价规则）**，不得只给一个审减率。

## 三、核对依据"四统一"
合同 + 投标报价（已标价工程量清单）+ 竣工图 + 变更签证，四者必须能相互印证；辅助证据为计量记录、验收记录、甲供材台账、影像资料。

## 四、证据要求（谁主张谁举证）
- 有效证据：双方签认的签证/变更单、监理确认的计量记录、发票与付款凭证、会议纪要（有签认）；
- 无效或效力不足：口头变更、单方自制的内部台账、事后补签且无旁证的材料；
- 甲供材料不得重复计取（已由甲方供应部分的价款须扣除）；
- 无有效签认的合同外签证不得计入结算。

## 五、造价审计的方法（审计明重点）
- 程序合规性：招标方式是否合规（是否化整为零规避招标）、合同是否与招标文件实质性一致、变更是否履行审批程序；
- 实质性核查：抽查分部分项（高价值项必查）、量价真实性、变更索赔合规性、待摊费用分摊合理性；
- 勾稽关系：各分项合价合计 = 报告汇总；支付累计 ≤ 审定应付；甲供材、预付、质保金扣抵关系闭环；
- 超概判定：实际与概算比较，偏差率显著为正需说明原因并提示超概风险。

## 六、竣工决算构成
建安工程投资 + 设备工器具投资 + 待摊投资（建设管理费、勘察设计费、利息等，须按合理标准分摊）+ 其他投资，形成交付使用资产价值。

## 七、审计结论与民事结算的关系
政府投资项目审计结论是财政监督结论，**不能当然否定合同约定的结算依据**；能否以审计结论作为结算依据，取决于合同约定与司法观点。本团只做造价与合规分析，不作法律定性。

## 八、工具
- 审减与明细：`--func audit_reduction`、`--func audit_reduction_detail --details "工程量核减:60;单价核减:40"`；
- 偏差：`--func variance --budget ... --actual ...`；
- 结算汇总：`--func settlement_total --items "800;150;80"`；
- 结构化交付：`deliverable.py`（结算审核 / 审计报告 / 索赔报告 / 指标报告，均自动过门禁自校验）。

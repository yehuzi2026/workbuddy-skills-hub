# 05 高频审计风险清单（核查用 Checklist）

## 一、程序合规
- [ ] 是否化整为零规避招标（施工 ≥400 万、货物 ≥200 万、服务 ≥100 万必须招标）；
- [ ] 合同是否与招标文件、投标文件实质性一致（是否签订背离实质性内容的其他协议）；
- [ ] 变更、签证是否履行事前审批（重大变更应事前审定，事后难以纠正）；
- [ ] 是否有无资质/挂靠、转包与违法分包迹象。

## 二、工程量与计价
- [ ] 工程量是否与竣工图、计量记录一致（重复计量、超范围计量）；
- [ ] 综合单价是否与已标价清单一致；擅自改组的单价；
- [ ] 工程量偏差是否超过 ±15% 并按约定调价（超幅不调的，须说明依据）；
- [ ] 甲供材料是否重复计取、是否按约定扣抵；
- [ ] 暂列金额/暂估价是否按实调整；
- [ ] 不可竞争费用（安全文明施工费、规费、税金）是否被让利或漏计。

## 三、变更、签证与索赔
- [ ] 变更是否有书面指令与签认；
- [ ] 签证是否及时签认、是否与现场实际相符（存在事后集中补签的需重点核查）；
- [ ] 索赔是否在 28 天内提出意向、证据链是否完整（三要素齐备）；
- [ ] 工期索赔是否按关键线路/总时差判定；
- [ ] 索赔费用与结算价款调整是否重复计取。

## 四、取费与税金
- [ ] 取费基数与费率是否与合同/计价办法一致；
- [ ] 计税方式（一般计税 9% / 简易计税 3%）是否与合同口径一致；
- [ ] 含税/除税口径是否全程一致，有无重复计税或漏计。

## 五、资金与支付
- [ ] 预付款比例是否在 10%~30%（或按合同），是否按材料比重扣回；
- [ ] 进度款支付是否在 60%~90%（或按合同）范围内；
- [ ] 是否有超付（累计支付 > 审定应付）；
- [ ] 质保金是否超过结算总额 3%；
- [ ] 逾期支付是否计息（不低于同期 LPR）。

## 六、决算与资产
- [ ] 待摊投资是否按合理基础分摊，是否全部塞入单一单体；
- [ ] 建安/设备/待摊/其他是否分类清晰、不混算；
- [ ] 竣工决算是否超概，超概是否有合规审批与说明。

## 七、指标与合理性
- [ ] 单方指标/含量指标是否在同业态、同口径、同时点下对标；
- [ ] 异常指标是否已区分"真异常"与"口径造成的伪异常"。

## 八、输出纪律
- [ ] 每个数字是否可溯源（条文号 / 数据来源 / calc_engine.py 实算证据）；
- [ ] 是否已过输出门禁（`gate.py emit/selfcheck`）并留痕；
- [ ] 是否已提示关键风险与待用户确认的假设。

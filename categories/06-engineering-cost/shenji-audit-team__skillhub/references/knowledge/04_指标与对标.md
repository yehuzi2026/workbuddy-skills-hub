# 04 造价指标与对标

## 一、指标定义
- 单方指标 = 总造价 ÷ 建筑面积（单位常用 元/㎡，也常用 万元/㎡ 表示）；
- 含量指标 = 某分项工程量 ÷ 建筑面积（如钢筋 t/㎡、混凝土 m³/㎡、模板 m²/㎡）。

## 二、口径（决定指标能不能用）
1. **面积口径**：建筑面积 / 使用面积 / 结构面积，分母不同结果差异极大，必须写明；
2. **造价口径**：含税 / 除税；是否含地下、精装、景观、市政配套、土方；
3. **时点**：不同年份的价格水平不同，跨年对标须做价格指数换算或注明时点；
4. **业态与地区**：住宅/公建/厂房/市政不可直接对标；不同地区人工与材料水平不同。

## 三、对标方法
- 多基准对标：同业均值、区域区间、限额指标、本单位历史项目；
- 偏差率 = (本项目指标 − 标杆指标) / 标杆指标；正 = 高于标杆，负 = 低于标杆；
- 偏差显著（如超过 ±10%~20%，按指标类型）先**怀疑口径**，再判断是否真异常；
- 工具：`--func index_metrics --total_cost 12000 --area 10000 --benchmark 1.0 --area_caliber 建筑面积`，`--func benchmark_index --benchmarks "同业均值:1.0;限额指标:1.1"`。

## 四、异常识别与优化
- 结构含量异常（钢筋/混凝土含量显著偏高）→ 设计或变更问题；
- 单方指标偏高但含量正常 → 价格/取费问题（材料价、费率、措施费）；
- 单方指标偏低 → 漏项或口径不含（精装、地下室）；
- 限额设计以指标约束设计，防止超标；指标是**经验参考**，不得作为审定结论或强制标准。

## 五、常见错误
- 拿含精装指标与不含精装指标对比；
- 用不同面积口径的指标互相比较；
- 样本不足（1~2 个项目）仍下"明显偏高/偏低"的确定性结论；
- 忽略价格时点，跨年直接比。

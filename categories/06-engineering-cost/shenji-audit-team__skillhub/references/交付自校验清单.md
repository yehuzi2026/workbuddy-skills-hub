# 工程造价审计AI助手 · 交付自校验清单

> 任何对外交付（报告/计算书/条款/清单/方案）发出前，逐项核对。A 红线不可破，B–E 须满足。

## A · 红线（15 条，触任一条禁止交付）
1. 无依据编造规范条款或数字。
2. 绕过 `gate.py emit` / `selfcheck` 输出含数值/条文/确定性结论。
3. 用 `SendMessage` 派单或要求回传（应只传 subagent_type）。
4. 传 `name` 派单触发 team 模式。
5. 替用户签审计/审定意见或越权决策。
6. 无证据认定造价。
7. 不顾合同约定强行套用某一版本计价依据（应写明约定版本与理由）。
8. 把经验指标/估值当强制标准或审定结论。
9. 不可比口径/业态/时点直接对标。
10. "审减率超阈值"直接判责而不列明细与条款。
11. 虚构案例、来源或数据出处。
12. 把示例占位数据（is_example）当作真实当地数据出结论。
13. 编造附件页码——页数未确定的附件页码一律留「（待填）」，不得跳页累加、不得估计凑数。
14. 把「电子数据校验值一致」当作「数据本身真实」的证明（校验值只证明文件未被改动）。
15. 以「情况说明」「已安排整改」代替销号证据——销号须有回访核实记录与实质性凭证。

## B · 证据（8 项）
1. 数值结论有 `calc_engine.py` 实算记录（非口算）。
2. 条文引用能在 `规范数据库.json` 找到出处（std_ref / clause），或已显式标注库外降级。
3. 价格/费率数据有来源声明（local_rates.json 期次 + 发布机构）。
4. 案例/数据有来源或脱敏说明。
5. 偏差/调整有逐项明细（量/价/费分类）。
6. 输出经门禁，留痕于 `references/search/gate_log.jsonl`（`gate.py log` 可查）。
7. 电子数据登记**三件套**（导出时间 + 记录数 + 校验值），且使用前已重算比对一致（`python ingest.py --hash <文件> --expect <登记值>`）。
8. 有档案时：报告附件目录与 `证据附件页码索引.md` 一致；审计日记的证据编号能与底稿索引互查；台账「已销号」项在 `整改回访记录.md` 中有对应回访与销号证据。

## C · 依据（5 项）
1. 每条结论附规范/公式依据。
2. 引用版本为现行有效或合同约定版本（查 `regulatory_register.md`；⚠️ 条目须先核验）。
3. 计算题给"读题→选公式→代入→验算→结论(带单位)"完整链。
4. 关键口径（面积/风险幅度/基准价/含税除税/调价阈值）已说明。
5. 不确定处标注"建议查阅规范[编号]/以官方最新文本为准"。

## D · 必须（9 项）
1. 角色身份正确，未在他人职责内代写。
2. 跨角色事项已提请主理人转派或升级。
3. 思考门禁五步自检全过。
4. 引擎输出门禁（emit/selfcheck）全过。
5. 数值经 `calc_engine.py` 实算，单位口径正确（严禁把"元"的组价结果标成"万元"）。
6. 单位/精度齐全，全文口径一致。
7. 关键风险/边界已提示（阈值边界、时效、暂列/暂估、甲供材、重复计取）。
8. 涉及用户敏感资料已脱敏。
9. 交付物可直接交付、无半成品（表格 + 报告 + 门禁等级）。

## E · 提示（5 条）
1. 审减率高 ≠ 报送方有责，须列审减明细与条款。
2. 指标对标须同业态、同口径、同时点。
3. 暂列金额/暂估价非确定价，不得直接计入。
4. 工期延误 ≠ 必然可获赔费用，须区分责任归属并分别论证工期与费用。
5. 工程建设强制规范（GB 550xx）与计价标准更迭频繁，以合同约定与现行有效版本为准。

## F · 交付前命令（照抄执行）
```bash
python calc_engine.py --selftest
python e2e_smoke_test.py
python content_check.py
python staleness_check.py --days 365
python references/search/gate.py selfcheck <交付文件>
python project_template.py --demo --out ./_档案示例        # 有档案交付时：确认 30 份全部放行
python ingest.py --hash <导出文件> --expect <登记值>       # 有电子取数时：确认文件未被改动
```

# 投标价格分析专家

## 核心定位

**目标不是"报个价"，而是帮用户通过投标中标后真正挣到利润。**

三维价格核算体系：
1. **定额基准价** — 政府发布的"官方指导价"，是价格的天花板/地板
2. **中标公示价** — 同类项目的真实成交价，反映市场竞争强度
3. **市场行情价** — 实时材料/人工/设备价格，反映当前真实成本

三者交叉验证，才能定出"既能中标、又有利润"的报价。

> 完整平台清单见 `references/platforms.md`：含省级造价站清单（10 省）、省级公共资源交易中心清单、保险类价格参考平台、爬虫可达性分级与 API 对接优先级/预估费用。

## 三维价格核算方法论

### 第一维：定额基准价（政府指导价）

**用途**：确定价格基准线，了解"官方认为这个值多少钱"。

**数据来源**：
| 平台 | 网址 | 覆盖范围 | 访问方式 |
|------|------|----------|----------|
| 各省市住建厅造价站 | 见下方省级清单 | 定额人工费、材料信息价、机械台班费 | WebSearch / WebFetch |
| 中国建设工程造价信息网 | cost.ccpc360.com | 全国造价招标中标信息 | WebSearch |
| 住建部工程造价信息网 | zaojia.mohurd.gov.cn | 国家级造价政策、标准 | WebSearch |

**省级造价站清单（重点省份）**：
- 广东：zjj.gd.gov.cn（广东省住建厅）
- 湖北：zjt.hubei.gov.cn（湖北省住建厅）— 用户所在省份
- 福建：zjt.fujian.gov.cn（福建省住建厅）— 东航酒店项目所在省份
- 浙江：jst.zj.gov.cn
- 江苏：jscin.jiangsu.gov.cn
- 四川：jst.sc.gov.cn

**操作方法**：
1. 用 WebSearch 搜索"[省份] [年份] [月份] 建设工程造价信息 信息价"
2. 用 WebFetch 抓取造价站页面，提取材料价格表
3. 对比定额本中的基期价格与当期信息价，计算价差

### 第二维：中标公示价（真实成交价）

**用途**：了解同类项目的真实中标价格，分析下浮率和竞争强度。

**数据来源**：
| 平台 | 网址 | 数据类型 | 访问方式 |
|------|------|----------|----------|
| 全国公共资源交易平台 | ggzy.gov.cn | 全口径工程交易数据、中标公告 | WebSearch / WebFetch |
| 中国招标投标公共服务平台 | cebpubservice.cn | 全国招标公告公示 | WebSearch / WebFetch |
| 各省公共资源交易中心 | 见 `references/platforms.md` | 省级中标公示 | WebSearch / WebFetch |
| 中国政府采购网 | ccgp.gov.cn | 政府采购中标公告 | WebSearch / WebFetch |

**操作方法**：
1. 用 WebSearch 搜索"[项目类型] [地区] 中标公告 [年份]"
2. 用 WebFetch 抓取中标公告页面，提取：中标金额、中标单位、招标控制价、下浮率
3. 汇总同类项目历史中标价，计算均价、中位数、下浮率分布
4. 分析竞争强度：投标人数量 vs 中标价/控制价比值

**关键指标**：
- **下浮率** = (招标控制价 - 中标价) / 招标控制价 × 100%
- **报价命中率** = 中标价 / 招标控制价 × 100%
- **竞争强度** = 投标人数量（>7家为高竞争，<3家为低竞争）

### 第三维：市场行情价（实时成本）

**用途**：掌握当前真实的市场材料/人工/设备价格，核算实际成本。

**数据来源**：
| 平台 | 网址 | 数据类型 | 访问方式 |
|------|------|----------|----------|
| 广材网 | gldjc.com | 建筑材料实时价格、信息价 | WebSearch / WebFetch / 爬虫 |
| 广联达材价通 | jzkt.glodon.com | 三重验证价（政府+市场+成交） | 需登录 |
| 造价通 | zaojiatong.com | 材料价格、人工费、机械费 | WebSearch |
| 钢材价格网 | gangcaijia.com | 钢材实时价格 | WebSearch |
| 中国水泥网 | ccement.com | 水泥价格指数 | WebSearch |
| 混凝土价格网 | hntsj.com | 混凝土价格 | WebSearch |

**操作方法**：
1. 用 WebSearch 搜索"[材料名称] [规格] [城市] 价格 [年月]"
2. 用 WebFetch 抓取价格页面，提取当期价格
3. 对比3个月前/6个月前的价格，分析价格趋势
4. 计算材料价格波动对总造价的影响

## 利润分析框架

### 投标报价利润测算模型

```
预期利润 = 投标报价 - 实际成本
实际成本 = 直接成本 + 间接成本 + 税费 + 风险准备金
直接成本 = 材料费(市场价) + 人工费(市场价) + 机械费(市场价) + 分包费
间接成本 = 管理费 + 临设费 + 其他措施费
```

### 报价策略矩阵

| 竞争强度 | 利润目标 | 报价策略 |
|----------|----------|----------|
| 高竞争（>7家） | 3%-5% | 贴近市场成本价，微利中标 |
| 中竞争（3-7家） | 5%-10% | 参考历史中标均价，适度下浮 |
| 低竞争（<3家） | 10%-15% | 参考控制价，适度下浮 |
| 独家/议标 | 15%+ | 参考控制价，合理报价 |

### 价格风险预警

- 材料价格波动 >5%：建议调价条款
- 人工费年涨幅 >8%：需考虑人工费调整
- 同类项目下浮率 >15%：竞争激烈，利润空间被压缩
- 中标价/控制价 <85%：可能低于成本，有亏损风险

## 不同投标场景的价格分析流程

### 场景1：建筑工程投标

1. **定额查询**：查项目所在地当期信息价，确定基准成本
2. **历史中标价**：搜同类项目近2年中标价，算下浮率分布
3. **市场材料价**：查主要材料（钢材、水泥、混凝土、砂石）当期市场价
4. **成本核算**：按工程量清单 × 市场价 = 直接成本
5. **报价决策**：直接成本 + 管理费(5-8%) + 利润(3-10%) + 税费 + 风险准备金(2-3%)
6. **验证**：报价 vs 历史中标价均价，偏差应 <10%

### 场景2：保险服务采购（如太平洋产险车险物损资源）

1. **历史中标价**：搜同类保险采购项目中标公告，提取保费费率、折扣率
2. **行业费率**：查银保监会/保险行业协会发布的基准费率
3. **自主定价系数**：参考同类项目的中标定价系数
4. **成本测算**：预估赔付率 + 运营成本 + 佣金
5. **报价决策**：确保保费收入 > 预估赔付 + 运营成本 + 合理利润

### 场景3：服务类采购（如酒店住宿服务）

1. **历史中标价**：搜同类住宿服务采购项目中标价
2. **市场价调研**：查携程/美团等平台的项目所在地酒店实时房价
3. **成本测算**：客房运营成本（布草洗涤+人工+能耗+物资）
4. **报价策略**：日均房价 × 天数 × 房间数，参考市场价适度优惠
5. **验证**：报价 vs 同类项目中标价，确保在合理区间

### 场景4：货物采购投标

1. **市场价调研**：查主要货物的出厂价/批发价/零售价
2. **历史中标价**：搜同类货物采购项目中标价
3. **成本测算**：采购成本 + 运输 + 仓储 + 管理 + 税费
4. **报价决策**：成本 + 合理利润（5-15%视竞争情况）

## GitHub 开源工具集成

以下工具可通过 clone 安装到本地，增强价格分析能力：

### 1. DDC-CWICR（开放式工程造价数据库）
- **仓库**：github.com/datadrivenconstruction/OpenConstructionEstimate-DDC-CWICR
- **内容**：55,000+ 工作项，27,000+ 资源，85字段/记录，支持中文
- **能力**：语义搜索、BOQ生成、跨区域价格对比、成本估算
- **格式**：Excel/Parquet/CSV/Qdrant向量快照
- **许可证**：数据 CC BY-NC 4.0，代码 Apache-2.0
- **适用场景**：建筑工程成本估算、定额查询、价格基准

### 2. Cost-RAG（工程造价智能RAG系统）
- **仓库**：github.com/whjyxl/Cost-RAG
- **内容**：基于RAG的造价咨询系统，支持PDF/Word/Excel
- **能力**：文档处理、智能分块、混合搜索、多LLM支持、成本优化
- **依赖**：Python 3.9+, PostgreSQL, Redis, 向量数据库
- **适用场景**：造价文档智能问答、定额库管理

### 3. BQlib（智能套价系统）
- **仓库**：gitee.com/kevin137/bqlib（Gitee）
- **内容**：基于语义理解的智能套价系统
- **能力**：项目描述自动匹配定额库条目，返回定额编号、价格
- **技术**：BGE-M3 语义模型 + FastAPI 后端 + React 前端
- **适用场景**：定额套用、工程量清单计价

### 4. 深圳造价信息爬虫
- **仓库**：github.com/SheZQ/sz_construction_price_data
- **内容**：爬取深圳市住建局工程造价信息
- **技术**：Playwright + SQLite
- **适用场景**：深圳地区材料信息价自动采集（可改造适配其他城市）

### 5. 广材网价格爬取工具
- **仓库**：gitee.com/huang-yuf-fa-shunfeng/fund（docs/gldjc_price_crawler_correct.py）
- **内容**：Selenium自动爬取广材网材料价格
- **能力**：批量材料价格查询，结果导出Excel
- **适用场景**：批量材料价格采集

## 使用方式

当用户说以下内容时自动激活本技能：
- "帮我分析这个项目的投标价格"
- "查一下[材料/项目]的市场价格"
- "这个报价有利润吗？"
- "帮我查同类项目的中标价"
- "这个定额价格是多少"
- "分析一下竞争情况"
- "报价策略建议"

### 标准分析流程

```
输入：招标文件/项目信息
  ↓
Step 1: 识别项目类型（建筑/保险/服务/货物）
  ↓
Step 2: 三维数据采集
  ├─ 定额基准价 → WebSearch 造价站信息价
  ├─ 中标公示价 → WebSearch 公共资源交易平台
  └─ 市场行情价 → WebSearch 材料价格网站
  ↓
Step 3: 成本核算
  ├─ 直接成本 = 材料 + 人工 + 机械 + 分包
  ├─ 间接成本 = 管理 + 措施 + 临设
  └─ 总成本 = 直接 + 间接 + 税费 + 风险准备金
  ↓
Step 4: 报价策略
  ├─ 竞争分析 → 同类项目投标人数量、下浮率
  ├─ 利润测算 → 不同报价方案的预期利润
  └─ 风险评估 → 材料价格波动、汇率、政策风险
  ↓
Step 5: 输出报告
  ├─ 价格分析报告（Markdown/PDF）
  ├─ 推荐报价区间
  └─ 利润测算表
```

# 招标文件提取规则参考

## 一、章节识别正则

### 1.1 一级章节标题

```regex
第[一二三四五六七八九十\d]+章\s*.+
第[一二三四五六七八九十\d]+节\s*.+
```

### 1.2 采购需求章节

```regex
关键词（任一匹配）：
- 采购内容及要求
- 采购需求
- 技术要求
- 货物需求一览表
- 设备清单
- 技术规格
- 技术参数
```

### 1.3 评分标准章节

```regex
关键词（任一匹配）：
- 评审的标准和方法
- 评审办法
- 评分标准
- 综合评分
- 评标办法
- 评标标准
- 评审因素
- 评审细则
```

### 1.4 合同章节

```regex
关键词（任一匹配）：
- 合同主要条款
- 合同草案
- 拟签订的合同文本
- 合同条款
- 合同格式
```

### 1.5 投标人须知

```regex
关键词（任一匹配）：
- 投标人须知
- 供应商须知
- 投标须知
- 前附表
```

## 二、★条款识别规则

### 2.1 显性标记

```regex
★.*
▲.*
【实质性要求】.*
【实质性条款】.*
【必须满足】.*
```

### 2.2 隐性标记

包含以下关键词的整句/整段：

```regex
- 废标条件
- 无效投标
- 投标无效
- 按废标处理
- 不允许偏离
- 不得偏离
- 必须满足
- 必须达到
- 不得低于
- 实质性响应
```

### 2.3 格式标记

- 加粗 + 下划线 组合的段落
- 红色/特殊颜色标注的段落
- 表格中用★标记的行

## 三、数字提取正则

### 3.1 数量类

```regex
(\d+)\s*[台套个件只]\s*[，,。.]
设备数量[：:]\s*(\d+)
共计[：:]\s*(\d+)
```

### 3.2 时间类

```regex
(\d+)\s*(个)?\s*(工作日|日历日|天|月|年)
工期[：:]\s*(\d+)
质保期[：:]\s*(\d+)
服务期[：:]\s*(\d+)
```

### 3.3 金额类

```regex
(\d+(?:\.\d+)?)\s*万?\s*元
预算[金额]?[：:]\s*(\d+(?:\.\d+)?)
最高限价[：:]\s*(\d+(?:\.\d+)?)
投标保证金[：:]\s*(\d+(?:\.\d+)?)
罚款[：:]\s*(\d+(?:\.\d+)?)
```

### 3.4 比例类

```regex
(\d+)%
百分之(\d+)
```

## 六、设备清单提取规则

### 标准设备描述模式

```
[序号][.、)]?\s*(.+?)\s+(\d+)\s*(台|套|个|件|只|米|吨|批)
```

### 数量汇总算法

```
total = sum(all qty values in equipment_list)
```

### 去重规则

- 同一设备名称 + 同一规格 → 合并数量
- 同一设备名称 + 不同规格 → 保留为独立条目
- 名称略有差异（如"台式计算机" vs "台式电脑"）→ 需人工判定

## 七、关键时间线提取规则（v0.2.0 新增）

### 7.1 P0~P8 时间字段识别模式

按项目生命周期 9 个阶段逐项提取：

```regex
P0 投标前 → 投标截止时间、开标时间、投标有效期、答疑截止

P1 交货/供货 → 供货期|交货期|交货时间|到货期限|配送期|供货周期
               /合同签订后\s*(\d+)\s*(?:个)?\s*(?:工作日|日历日|天|日)\s*内[交送供]/

P2 安装/施工 → 安装工期|施工工期|建设工期|部署时间|安装调试期
               /(\d+)\s*(?:个)?\s*(?:工作日|日历日|天)\s*部署完毕/

P3 服务/运营 → 服务期|运营期|合同[履行服务]期限|服务年限|合作期限|租赁期|特许经营期
               /合同服务期\s*(\S+年|\d+年)/
               /"(\d+)\+(\d+)"\s*模式.*续签/    # "1+1"续签模式

P4 质保/售后 → 质保期|保修期|免费维护期|售后服务期
               /质保期.*不低于\s*(\d+)\s*年/

P5 响应/修复 → 响应时间|到场时间|修复时限|故障恢复时间|售后响应
               /(\d+)\s*小时.*响应.*(\d+)\s*小时.*修复/

P6 付款/结算 → 付款期限|结算周期|付款时间|结算方式
               /验收合格[后之]\s*(\d+)\s*[个]?\s*[日天工作日内].*付/

P7 验收/试运行 → 验收期限|验收时间|试运行期|试用期
                 /安装[完成毕].*\s*(\d+)\s*(?:个)?\s*工作日.*验收/

P8 违约/解约 → 罚款梯度|解约条件|违约金|整改期限
               /(?:逾期|超期|延期).*?罚[款金].*?(\d+).*?元/
               /超.*?(\d+).*?[天日].*?解约|解除合同|终止合同/
```

### 7.2 罚款梯度结构化提取

罚款梯度常见三种模式：

```
模式A — 福建模式：超1天罚5000元，超3天罚15000元，超7天解约
模式B — 比例模式：每逾期1天，按合同金额的万分之五支付违约金
模式C — 阈值模式：逾期超过X天，采购人有权单方解除合同
```

提取后结构化存储：

```json
{
  "penalty_gradient": [
    {"threshold": "1天", "penalty": "5000元", "type": "罚款"},
    {"threshold": "3天", "penalty": "15000元", "type": "罚款"},
    {"threshold": "7天", "penalty": "解约", "type": "废标"}
  ]
}
```

### 7.3 时间交叉验证规则

提取后自动执行，发现问题标记 warning：

| 验证项 | 规则 | 示例 |
|--------|------|------|
| 部署可行性 | P1+P2 ≤ P3 | 供货30天+安装10天 ≤ 服务期8年 ✅ |
| 可用率底线 | P5累计 ≤ P3×1% | 每次修复48h × 月均故障2次 × 96月 = 9600h < 70080h×1% ✅ |
| 解约合理性 | P8触发 ≤ P3 | 超7天解约 ≤ 8年 ✅ |
| 投标顺序 | P0截止 > 公告日期 | 8.19截止 > 8.8公告 ✅ |

### 7.4 项目类型与时间优先级自动判定

| 判定关键词 | 项目类型 | 核心时间字段 |
|-----------|---------|------------|
| 设备清单 + 供货 + 验收（无运营） | 纯设备供货 | P1, P2, P4, P7 |
| BOT/投资/运营/使用者付费 | BOT投资运营 | P2, P3, P5, P8 |
| 服务/配送/陪护/保洁（无设备清单） | 服务配送类 | P1, P3, P5, P6 |
| 以上混合 | 设备+服务混合 | P1~P8 全部 |

## 八、特殊场景处理

### 7.1 分册招标文件

若招标文件分为多册（如第一册/第二册/第三册），优先处理：
1. 包含"采购需求"的分册
2. 包含"评分标准"的分册
3. 包含"投标人须知"的分册

### 7.2 更正/澄清文件

若有更正公告或澄清文件：
- 以更正后内容为准
- 在 JSON meta 中标注"含更正文件"
- 对冲突项注明原值和更正值

### 7.3 多包/多标段

若招标文件包含多个包（包1/包2/...）：
- 每个包独立提取 A~H 类信息
- 输出为包维度的 JSON 数组
- 标注各包之间的差异点

## B. Phase 5.5.2 DOCX 13 项自动化验证

> 以下 13 项检查合并为一个验证脚本 `scripts/verify_docx_format.py` 批量执行，
> 输出统一报告 `phase5_docx_verification.json`。**任意一项不通过 → 不得交付，必须修正后重新验证。**

### B.1 字体/字号/颜色逐项验证（5.5.2a + 5.5.2g）
| # | 检查对象 | 字体 | 字号 | 颜色 | 加粗 | 缩进 |
|---|---------|------|------|------|------|------|
| 1 | 正文文字 | 宋体 | 12pt(小四) | #000000 | 否 | 0.74cm |
| 2 | H1 一级标题 | 宋体 | 14pt(四号) | #000000 | 是 | 0 |
| 3 | H2 二级标题 | 宋体 | 14pt(四号) | #000000 | 否 | 0 |
| 4 | H3 三级标题 | 宋体 | 12pt(小四) | #000000 | 否 | 0 |
| 5 | 表格文字 | 宋体 | 10.5pt(五号) | #000000 | 否(表头白字) | 0 |
| 6 | 图片标题 | 宋体 | 9pt(小五) | #000000 | 否 | — |

额外验证：所有标题段落 `style.name` 必须含 "Heading"，不可为 "Normal"（此项失败 = TOC 不可用）

### B.2 分页符逐级验证（5.5.2b + 5.5.2k）
- H1 分页符数 == H1总数-1（第一个不分页）
- H2 分页符数 == H2总数 - 含有H2子节点的H1数量（每个H1章节下第一个H2不分页）
- H3 分页符数 == H3总数 - 含有H3子节点的H2数量（每个H2节下第一个H3不分页）
- DOCX 总硬分页符数 == 以上三项之和
- **v3.1.1 修正**：原公式 H2总数-H1总数、H3总数-H2总数 在存在"空节"（H1下无H2、或H2下无H3，如附录）时会低估实际分页符数量。修正为按"实际有子节点的上级数量"计算。

### B.2.5 多级列表自动编号（5.5.2l，v3.1.1 新增）
- H1 编号样式：一、二、三、（通过 Word 多级列表链接到 Heading 1 样式）
- H2 编号样式：（一）（二）（三）（链接到 Heading 2）
- H3 编号样式：1. 2. 3.（链接到 Heading 3）
- 标题文本中不再手写序号（如"# 二、运营方案" → "# 运营方案"），序号由 Word 自动生成
- 验证：修改 H1 顺序后更新域，编号自动重排；TOC 中编号一致

### B.3 正文段落序号全局验证（5.5.2c）
- 一级：全部"一、二、三"（禁止阿拉伯数字/罗马数字/带括号）
- 二级：全部"1. 2. 3."（禁止（1）或 1）或 a.）
- 三级：全部"（1）（2）（3）"（禁止 1）或 ◆ 或 ●）
- 四级：全部"1）2）3）"（禁止项目符号或字母）
- 全文无 ● ◆ ? a. b. c. i. ii. iii.

### B.4 表格列宽自适应验证（5.5.2d）
- 列宽按内容比例自适应（非等宽）
- 数据列 <=15% 表宽，描述列 >=30% 表宽
- 表格整体宽度撑满页面
- 无单元格文字挤压成单字竖排
- 表头色系：#4472C4 深蓝（彩色）或 #333333（黑白）
- 斑马纹（仅彩色）：奇数行 #F0F3FA / 偶数行 #FFFFFF
- 表格文字 first_line_indent == 0

### B.5 标题层级完整性验证（5.5.2e）
- 导航窗格：H1/H2/H3 全部显示
- 目录正确：TOC 后第一页为第一个 H1
- 无层级缺失：有 H1 和 H3 但不能没有 H2
- 目录条目与正文标题一一对应（Ctrl+A F9 刷新后）

### B.6 Markdown 语法残留全局扫描（5.5.2f）
- 表格外搜索 `|`、`---`、`**`、`![](`、`* ` 残留

### B.7 全量行距 1.5 倍验证（5.5.2h）
- 正文/表格单元格/TOC域/空行/图片标题 → 行距 1.5 覆盖率 = 100%

### B.8 表格单元格垂直居中 + 多行左对齐（5.5.2i）
- 所有单元格 vAlign = center（先删旧的再设新的）
- 所有单元格 paragraph_format.space_before = space_after = Pt(0)
- 多行单元格 w:jc = left + first_line_indent = 0
- 单行单元格 p.alignment = CENTER

### B.9 图片嵌入验证（5.5.2j）
- 三链检查：Step 2.6 路径收集 → Phase 3 MD 占位符 → Phase 5 doc.add_picture()
- ![]() 语法已删除（未残留）
- DOCX 中 embedded pictures 数量 == 有图章节数
- 全文 [图片未找到] == 0 且 [图片加载失败] == 0
- 无重复标题（![]() + 文字标题双重写入）

### B.10 表格转换验证
- Markdown 表数 == DOCX doc.tables 长度

### B.11 TOC 域名验证
- TOC 域已插入（提示语为中文）

### B.12 内容俗套语验证
- 全文搜索 `【对采购人的实用价值】``对采购人的价值` → 0 处残留

### B.13 双版本×双色系验证（四变体）
- 打印版+彩色 / 打印版+黑白 / 粘贴版+彩色 / 粘贴版+黑白
- 四个变体各自验证通过

**检测输出：** `phase5_docx_verification.json`（13 项通过/失败状态 + 失败详情）

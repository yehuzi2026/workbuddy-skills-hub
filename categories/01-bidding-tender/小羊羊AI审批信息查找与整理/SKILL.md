# 小羊羊AI审批信息查找与整理

## 技能用途

本技能用于自动搜索和整理各省政府投资项目的审批/招标信息，输出结构化的Excel报告。

## 支持的省份和数据源

| 省份 | 发改委公示 | 公共资源交易平台 | 搜索关键词 |
|------|-----------|----------------|-----------|
| 江苏省 | fzggw.jiangsu.gov.cn | jsggzy.jszwfw.gov.cn | 教学楼、宿舍楼、学校、医院 |
| 浙江省 | fgw.zjol.com.cn | zjpubservice.zjzwfw.gov.cn | 教学楼、宿舍楼、学校、医院 |
| 广东省 | drc.gd.gov.cn | gdgpo.czt.gd.gov.cn | 教学楼、宿舍楼、学校、医院 |

> 更多省份配置见 `references/provinces_config.md`

## 搜索流程

### 1. 收集需求

- 确定省份（必填）
- 确定项目类型（必填），如：教学楼、宿舍楼、医院、道路、桥梁
- 确定时间范围（**必填，固定为近1年**）
- 确定输出格式（默认Excel）

### 2. 执行搜索

**【重要】搜索范围限制：仅搜索近1年内的项目数据**

使用 WebSearch 和 WebFetch 工具访问以下数据源：

```
1. 省级发改委办件公示页面
2. 省级公共资源交易网
3. 市级发改委/公共资源交易平台
4. 项目所属单位官网（如高校基建处）
```

**时间过滤规则**：
- 仅保留发布时间在近1年内的项目
- 超过1年的项目直接过滤，不纳入报告
- 当前日期与项目发布时间间隔超过365天则不收录

### 3. 数据校验

| 校验项 | 方法 |
|--------|------|
| URL有效性 | 使用 WebFetch 直接访问验证 |
| 重复项目 | 按项目名称+单位去重 |
| 时间逻辑 | 发布时间 ≤ 批复时间 |
| 字段完整 | 必填：项目名、单位、时间、URL |

### 4. 生成报告

运行 `scripts/generate_report.py` 生成Excel报告：

```bash
python scripts/generate_report.py --projects "<项目JSON>" --output "<输出路径>"
```

或直接调用 Write 工具写入Excel生成脚本。

## 输出格式

Excel表格包含以下字段：

| 序号 | 学校/单位 | 项目名称 | 项目类型 | 审批状态 | 发布时间 | 官方网址 | 数据来源 | 备注 |
|------|----------|---------|---------|---------|---------|---------|---------|------|

## 注意事项

- 政府网站可能有访问限制，多次失败时尝试备用数据源
- 优先使用官方网址，避免使用第三方转载
- 标注"✅已验证"和"⚠️待核实"，便于用户判断
- 搜索结果尽量控制在50个项目以内，避免信息过载
- 对于不确定的项目，建议用户直接访问官方网址核实

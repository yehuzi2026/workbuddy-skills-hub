# 共享格式参数 — 唯一权威源

> 本文件为四技能组合流程中所有格式参数的**唯一权威定义源**。
> 编写技能 Phase 5.5 以此生成 DOCX；监督技能和排版技能以此为校验基准。
> 修改任何参数，只需改这一个文件。

---

## 一、字体规范

| 元素 | 字体 | 字号 | 加粗 | 颜色 |
|------|------|------|:---:|------|
| H1 一级标题 | 宋体 | 14pt（四号/28半点） | 是 | #000000 |
| H2 二级标题 | 宋体 | 14pt（四号/28半点） | 否 | #000000 |
| H3 三级标题 | 宋体 | 12pt（小四/24半点） | 否 | #000000 |
| 正文 | 宋体 | 12pt（小四/24半点） | 否 | #000000 |
| 表格文字 | 宋体 | 10.5pt（五号/21半点） | 否 | #000000 |
| 图片标题 | 宋体 | 9pt（小五/18半点） | 否 | #000000 |

> 标题字体三步骤干净设置规则见编写技能 Phase 5.5。

## 二、页面布局

| 参数 | 值 |
|------|-----|
| 页边距（上/下） | 2.54cm |
| 页边距（左/右） | 3.18cm |
| 行距 | 1.5 倍（全文统一，含正文/标题/表格/TOC/空行/图片标题） |
| 正文首行缩进 | 0.74cm（24pt / 2字符） |
| 页码 | 底部居中 |

## 三、分页符规则

| 标题级别 | 分页规则 | 例外 |
|----------|----------|------|
| H1（章） | 每个 H1 前加分页符 | 第一个 H1（紧跟目录之后）除外 |
| H2（节） | 每个 H2 前加分页符 | 紧接 H1 的第一个 H2 除外 |
| H3（小节） | 每个 H3 前加分页符 | 紧接 H2 的第一个 H3 除外 |

## 四、表格格式

### 4.1 表头样式

| 模式 | 表头底色 | 表头文字色 | 数据行斑马纹 |
|------|---------|----------|------------|
| 彩色（默认） | #4472C4 | #FFFFFF 加粗 | 奇数行 #F0F3FA / 偶数行 #FFFFFF |
| 黑白 | #333333 | #FFFFFF 加粗 | 统一 #FFFFFF |

### 4.2 表格密度标准

| 方案总字数 | 推荐表格数 | 最低要求 |
|-----------|:---:|:---:|
| 3万字 | 15-25 张 | ≥10 张 |
| 5万字 | 25-40 张 | ≥15 张 |
| 7万字 | 35-55 张 | ≥20 张 |

> 0 表格方案 = 自动判定不合格。

### 4.3 四层设计法（引名形释）

| 层级 | 名称 | 规范 |
|:---:|------|------|
| 1 | 引 | 表格前必须有引导文字（数据引/对比引/破折号引） |
| 2 | 名 | 表格必须有带编号的标题：`表X-X 项目简称+概括` |
| 3 | 形 | 深蓝表头(#4472C4)白字 + 列宽自适配 + 垂直居中 + 表格首行缩进归零 |
| 4 | 释 | 表格后必须有收束句："由上表可见，[结论]，[呼应评分标准]。" |

## 五、序号体系

| 层级 | 序号格式 | 适用范围 |
|:---:|---------|---------|
| 粗体子标题 | **（1）（2）（3）…粗体** | H3 节内 ≥3 个并列子话题 |
| 正文一级 | 1. 2. 3. … | 所有正文段落 |
| 正文二级 | （1）（2）（3）… | 正文一级下的子点 |
| 正文三级 | 1）2）3）… | 正文二级下的子点 |
| 正文四级 | - 或 a）b） | 正文三级下的列表项 |

---

## 六、标点符号规范

全文标点统一中文全角（，。；：""（）——《》），例外：招标文件原文引用中的英文标点保留。

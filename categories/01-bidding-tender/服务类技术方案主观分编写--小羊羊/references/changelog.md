### v2.0.0 详细变更 (2026-05-30)

**工作流升级：**
- 从 4 Phase 扩展到 7 Phase（+ 可选 Phase 7 PDF 转换）
- Phase 0 新增自动填充模式（bidding_profile.json 检测）和包/标段确认
- Phase 1-2 拆分评分分析和方案结构规划为独立阶段
- Phase 3 拆分为 3A（首章验证）+ 3B（连续写作）
- Phase 4 新增三层质量校验（4A 自动校验 + 4B 人工审阅 + 4C 评分覆盖率）
- Phase 5 新增图片插入 + Phase 5.5 DOCX 生成升级
- Phase 6 新增排版技能调用 + 交付汇总

**核心纪律：**
- 引入 8 条核心纪律（①不可忘记 ②不可遗漏 ③不可跳过 ④数字目标直达 ⑤质量前置 ⑥图片不遗忘 ⑦内容不俗套 ⑧禁用子Agent写作）

**自动填充：**
- 引入 bidding_profile.json 字段映射（A-I 九大类）
- 服务类适配映射（设备清单→服务范围、楼栋/地点→服务区域/地点）

**断点续传：**
- 引入 checkpoint.json（精确到二级标题粒度）
- 支持断点恢复、质量门记录、字数追踪

**质量保障：**
- 引入六道初写质量门（内容合规/风格合规/内容质量/蓝本一致性/数量达标/结构完整）
- Phase 4A 四项自动校验（字数/交叉验证/长短句/英文扫描）+ 回归验证
- Phase 4B 人工审阅清单（错别字/通顺/AI味/自创数值/背景符合度）
- Phase 4C 评分覆盖率预估（全覆盖/部分覆盖/未覆盖 + 预估得分区间）

**编写原则：**
- 从 5 条简版升级到 20 条完整原则
- 服务类语境适配（技术底座→服务需求底座、设备总数→人员总数/服务面积）
- 引入英文禁令（单一来源原则）
- 引入项目特征深度锚定（≥3处本项目特征）
- 引入管理理念先进性（≥3种先进管理方法）

**文档生成：**
- DOCX 生成升级到 38+ 格式化规则（标题内置样式、宋体百分号标准化、×占位符红色标记、表格四层设计、行距全覆盖、分页符三级覆盖）
- Phase 6 调用标书方案排版技能
- Phase 7 可选 DOCX→PDF 转换

**新建文件：**
- `references/writing-principles.md` — 20 条服务类编写原则
- `references/generic-elements.md` — 服务类通用要素表
- `references/legal-references.md` — 服务类法规引用库
- `scripts/insert_images.py` — 图片插入脚本
- `assets/index.json.template` — 图片索引模板

**修改文件：**
- `SKILL.md` — 从 ~158行重写为 ~800行
